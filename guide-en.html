Language Made Easy is an Obsidian plugin that brings word lookup, flashcards, video shadowing, and AI analysis right into your note-taking workflow — so you pick up a language naturally while reading articles, watching videos, and taking notes.

1. Install the Plugin

📦 Download & Install

  1. Copy the plugin files (main.js, manifest.json, style.css) into your Obsidian vault's plugins folder:
your-vault/
└── .obsidian/
    └── plugins/
        └── language-made-easy/
            ├── main.js
            ├── manifest.json
            └── style.css
💡 How do I find the plugins folder?

In Obsidian, open Settings → Community plugins → click the 📁 icon to jump straight to the plugins folder.

  1. Back in Obsidian, go to Settings → Community plugins, find Language Made Easy, and toggle it on.

The best way to learn a new language is not through memorization, but through immersion. When you read, listen, and speak in context, your brain absorbs vocabulary and grammar naturally — just like how you learned your first language as a child.

3. Adding & Managing Flashcards

🎴 Once you've collected plenty of new words from reading and lookups, here's how to review them systematically:

Auto-generated Flashcards

When you click "Add to word book" after a lookup, the plugin generates a flashcard for you automatically. Each card includes:

  • ✅ Word + phonetics
  • ✅ Definition
  • ✅ Word context (from where you looked it up in the note)
  • ✅ Link to the source note
  • ✅ Date added

Add a Flashcard Manually

Open the flashcard review panel → click the "Add Flashcard" button at the bottom
→ Fill in word, phonetics (optional), definition, example sentence (optional)
→ Save

Start Reviewing

Open the flashcard review panel:

Option 1: Click the 🧠 brain icon in the left sidebar
Option 2: Ctrl/Cmd + P → search "Start flashcard review"

Review Flow

👀 See the front of the card → 🤔 Try to recall the meaning
→ 🖱️ Click to flip and reveal the definition → ⭐ Rate how well you remembered

Rating Scale

🧠 About the FSRS Algorithm

Flashcard review is powered by the FSRS algorithm (a modern spaced-repetition algorithm). Based on your ratings, it intelligently schedules each card's next review so you revisit it right at the edge of forgetting.

RatingMeaningEffect
😵 ForgotCouldn't recall it at allShows up again soon
😐 HardBarely recalledInterval shortened
🙂 GoodRecalled normallyStandard interval scheduled
😎 EasyKnew it instantlyInterval greatly extended
🧹 Auto-cleanup

After a word is marked "Easy" several times, it's automatically removed from the review rotation. You can customize the trigger for the "auto-cleanup" feature under Settings → Language Made Easy.

Manage Flashcard Data

Ctrl/Cmd + P → search "Manage flashcard data"

In the manager you can:

  • 📋 Filter flashcards by language and status
  • 🗑️ Batch-delete flashcards you no longer need
  • 📤 Export your flashcard data
💡 Two important notes

1. Flashcard data is stored in local IndexedDB. When updating the plugin, you only need to replace the three files main.js, manifest.json, and style.css — your existing flashcards won't be affected. Update with confidence!

2. Flashcards support import and export in multiple formats — txt, markdown, csv, json, and more — for easy backup and migration.

4. Using the Shadowing Studio

🎬 Language Made Easy helps you learn more efficiently from YouTube / Bilibili videos, so you can pick up natural spoken language and sharpen your listening skills.

Open the Shadowing Studio

Option 1: Click the ▶️ play icon in the left sidebar
Option 2: Ctrl/Cmd + P → search "Shadowing Studio"

Load a Video

Paste a video link into a note and the plugin recognizes and loads it automatically:

✅ YouTube video → paste the link to auto-load
✅ Bilibili video → paste the link to auto-load (auto-downloaded & cached)
✅ Local audio/video → embed with ![[video.mp4]] or ![[audio.mp3]]

Download Subtitles

After loading a video, click the "Download Subtitles" button in the right toolbar. The plugin fetches subtitles from YouTube / Bilibili and inserts them into your note.

Subtitle format example:

[00:12] Hello, how are you today?
[00:15] I'm fine, thank you. And you?
[01:23] What a beautiful day! Let's go for a walk.
📝 Note

The Shadowing Studio supports multiple timestamp formats — whether HH:MM:SS, MM:SS, or [00:12], they're all recognized and loaded automatically.

Playback Controls

The Shadowing Studio player has a row of playback controls at the bottom:

ButtonFunctionShortcut
⏮️ ReplayJump to the start of the current sentenceRe-listen from the sentence start
🔁 RepeatSingle-sentence loopGreat for drilling one sentence
▶️ / ⏸️ Play/PauseControl playbackSpacebar
🐢🐇 Speed0.8x / 1.0x / 1.2xAdjust to your level

🎧 Dictation Mode

Want to challenge your listening? Try Dictation Mode!

Shadowing Studio right toolbar → click the "Dictation Mode" button
→ A sentence plays and you type what you hear
→ On submit, your input is compared with the original
→ Mistakes are marked red; correct parts are marked green

5.6 More Ways to Load Subtitles

Beyond downloading subtitles directly in the Shadowing Studio, there are several other ways to load subtitles:

5.6.1 Use the Shadowing Studio's "Download Subtitles" button

The most direct method. After loading a video, click the "Download Subtitles" button in the right toolbar — the plugin fetches subtitles from YouTube / Bilibili automatically.

⚠️ Subtitle download notes

1. The plugin downloads subtitles for the currently selected language — please double-check the language before downloading. If no subtitle is found for that language, the video's default subtitles are returned instead.

2. Bilibili videos often do not include English subtitles. Before choosing a video, check the "字幕" (Subtitles) list in Bilibili's player to confirm the language you need is available.

5.6.2 Use the Obsidian Web Clipper

With the Obsidian Web Clipper browser extension, you can clip YouTube subtitles straight into an Obsidian note while watching.

Install the Obsidian Web Clipper browser extension
→ On the YouTube video page, click the extension icon
→ Choose to clip the subtitle content
→ It's automatically saved as a timestamped note

5.6.3 Use the ytranscript plugin

ytranscript is another Obsidian plugin that helps you download YouTube subtitles inside Obsidian:

Search for and install "ytranscript" from Obsidian's community plugins
→ Use ytranscript from the command palette to fetch YouTube subtitles
→ Subtitles are inserted into the note with timestamps
→ Open the Shadowing Studio to start using them

5.6.4 Load SRT files for local videos

If you have a local video file and a matching SRT subtitle file:

Option 1: Copy the SRT file content into a note
         → Make sure the SRT timestamp format is correct
         → Embed the video in the note with ![[video.mp4]]
         → Open the Shadowing Studio to parse the video and subtitles

Option 2: Place the SRT file next to the video file in your vault
         → Embed the video in the note with ![[video.mp4]]
         → The plugin auto-matches the SRT file with the same name

7. FAQ

❓ Lookup isn't responding?

Please check the following:

1. Make sure a dictionary is properly configured (online dictionaries need a network connection).

2. If you're using an MDX dictionary, double-check that the mdx, mdd, and css file paths are filled in correctly in the settings.

3. Confirm the current study language is set correctly.

❓ Can't see the flashcard I just added?

Newly added flashcards appear at the very end of the review queue.

❓ Bilibili videos only download Chinese subtitles?

Check whether the video actually has subtitles in other languages uploaded. Burned-in bilingual subtitles on screen don't mean the uploader provided all of those subtitle files.

❓ The Shadowing Studio asks me to "sign in" when opening a YouTube video?

Switching networks usually resolves this. It's typically related to your current network environment — try a different network node and retry.

❓ AI analysis throws an error?

Please check:

1. Is the API key configured correctly?

2. Is your network connection working?

3. Is the API balance sufficient?
