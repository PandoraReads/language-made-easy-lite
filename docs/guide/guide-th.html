Language Made Easy · คู่มือการใช้งาน

ปลั๊กอิน Obsidian สำหรับเรียนภาษาแบบดื่มด่ำ · ค้นคำศัพท์ / การ์ดคำศัพท์ / แชโดว์ / AI

ติดตั้งค้นคำศัพท์การ์ดคำศัพท์แชโดว์AIเพิ่มเติมคำถามที่พบบ่อย

Language Made Easy คือปลั๊กอิน Obsidian ที่รวม การค้นคำศัพท์ แฟลชการ์ด แชโดว์วิดีโอ และการวิเคราะห์ด้วย AI ไว้ในสายการทำงานการจดบันทึกของคุณ — ช่วยให้คุณซึมซับภาษาอย่างเป็นธรรมชาติระหว่างอ่านบทความ ดูวิดีโอ และจดโน้ต

1. ติดตั้งปลั๊กอิน

📦 ดาวน์โหลดและติดตั้ง

  1. คัดลอกไฟล์ปลั๊กอิน (main.js, manifest.json, style.css) ไปยังโฟลเดอร์ปลั๊กอินของคลัง Obsidian:
your-vault/
└── .obsidian/
    └── plugins/
        └── language-made-easy/
            ├── main.js
            ├── manifest.json
            └── style.css
💡 หาโฟลเดอร์ปลั๊กอินยังไง?

ใน Obsidian เปิด การตั้งค่า → ปลั๊กอินชุมชน → กดไอคอน 📁 เพื่อไปที่โฟลเดอร์ปลั๊กอินทันที

  1. กลับมาที่ Obsidian เข้า การตั้งค่า → ปลั๊กอินชุมชน ค้นหา Language Made Easy แล้วเปิดใช้งาน

🆓 ทดลองใช้ฟรี 3 วัน → เวอร์ชันเต็ม

ตั้งแต่เปิดใช้ครั้งแรกจะเริ่ม ช่วงทดลองใช้ฟรี 3 วัน — ทุกภาษาเปิดให้เรียน (ค้นคำศัพท์ แฟลชการ์ด FSRS แชโดว์วิดีโอ วิเคราะห์ AI) ด้วยชุดฟีเจอร์พื้นฐาน ตัวนับถอยหลังแสดงในแถบสถานะ

เมื่อหมดช่วงทดลอง ใช้งานต่อได้ด้วยการซื้อ เวอร์ชันเต็ม (จ่ายครั้งเดียว อัปเดตตลอดชีพ) ปลดล็อกทุกโมดูลขั้นสูง:

  • ภาษาเพิ่มอีก 7 ภาษา: อังกฤษ / เยอรมัน / ฝรั่งเศส / สเปน / เกาหลี / รัสเซีย / ญี่ปุ่น
  • การ์ดไม่จำกัด พจนานุกรมในเครื่อง 5 เล่ม พจนานุกรมออฟไลน์บนมือถือ
  • ซิงก์การ์ดข้ามเครื่อง นำเข้า / ส่งออกข้อมูล
  • สร้างการ์ดเป็นชุดด้วย AI ส่งออกรายงาน AI
  • ธีมหน้าจอเพิ่มอีก 9 แบบ โหมดทบทวนฟังเสียง / พิมพ์
  • บุ๊กมาร์กวิดีโอ การ์ดบรรยายวิดีโอ ดาวน์โหลดคลิกเดียวและเป็นชุดจากหน้าติดตาม

🌐 ซื้อเวอร์ชันเต็มที่ https://languagemadeeasy.com

2. ใช้งานการค้นคำศัพท์

📖 ตัวอย่างบทความภาษาอังกฤษ:

The best way to learn a new language is not through memorization, but through immersion. When you read, listen, and speak in context, your brain absorbs vocabulary and grammar naturally — just like how you learned your first language as a child.

ลอง ดับเบิลคลิกคำไหนก็ได้ที่ไม่รู้จักในย่อหน้าด้านบน เพื่อลองฟีเจอร์ค้นคำดู!

เปิดผู้ช่วยคำศัพท์

เปิดได้หลายวิธี:

วิธีที่ 1: กดไอคอนหนังสือ 📖 ในแถบข้างซ้าย
วิธีที่ 2: Ctrl/Cmd + P → ค้นคำอัตโนมัติด้วย「ผู้ช่วยคำศัพท์」

สิ่งที่ทำได้หลังค้น

ดับเบิลคลิกคำในโน้ต หรือ กดค้าง Ctrl/Cmd + Shift แล้วเลือกข้อความ แผงผลลัพธ์จะเด้งขึ้นด้านขวาอัตโนมัติ

แผงผลลัพธ์การค้น

ค้นคำแล้วคุณจะเห็น:

ฟีเจอร์คำอธิบาย
🔊 การออกเสียงกดเพื่อฟังเสียงอ่านที่ถูกต้อง
📝 เพิ่มเข้าสมุดคำศัพท์บันทึกเป็นการ์ดในคลิกเดียวไว้ทบทวนภายหลัง
🔤 คำอ่านแสดงคำอ่านตามสัทอักษร
📖 ความหมายแสดงชนิดคำและความหมาย
✨ เคล็ดลับ

ในแผงผลลัพธ์ก็ ดับเบิลคลิกค้นคำ ได้เช่นกัน — ตัวพจนานุกรมเองก็เป็นสื่อการเรียนที่ดีมาก!

3. เพิ่มและจัดการการ์ดคำศัพท์

🎴 เมื่อคุณเก็บคำใหม่จากการอ่านและการค้นได้เพียบแล้ว มาดูวิธีทบทวนอย่างเป็นระบบ:

การ์ดที่สร้างอัตโนมัติ

เมื่อคุณกด 「เพิ่มเข้าสมุดคำศัพท์」หลังค้นคำ ปลั๊กอินจะสร้างการ์ดให้อัตโนมัติ การ์ดแต่ละใบมี:

  • ✅ คำศัพท์ + คำอ่าน
  • ✅ ความหมาย
  • ✅ บริบทของคำ (จากโน้ตที่ค้นพบ)
  • ✅ ลิงก์ไปยังโน้ตต้นทาง
  • ✅ วันที่เพิ่ม

เพิ่มการ์ดด้วยตัวเอง

เปิดแผงทบทวนการ์ด → กดปุ่ม「เพิ่มการ์ด」ด้านล่าง
→ กรอกคำศัพท์ คำอ่าน (ทางเลือก) ความหมาย ประโยคตัวอย่าง (ทางเลือก)
→ บันทึก

เริ่มทบทวน

เปิดแผงทบทวนการ์ด:

วิธีที่ 1: กดไอคอนสมอง 🧠 ในแถบข้างซ้าย
วิธีที่ 2: Ctrl/Cmd + P → ค้นหา「เริ่มทบทวนแฟลชการ์ด」

ขั้นตอนการทบทวน

👀 ดูด้านหน้าการ์ด → 🤔 พยายามนึกความหมาย
→ 🖱️ กดพลิกเพื่อดูเฉลย → ⭐ ให้คะแนนว่าจำได้ดีแค่ไหน

เกณฑ์การให้คะแนน

🧠 เรื่องอัลกอริทึม FSRS

การทบทวนขับเคลื่อนด้วย อัลกอริทึม FSRS (อัลกอริทึมจัดความจำแบบเว้นระยะยุคใหม่) จากคะแนนที่คุณให้ ระบบจะจัดตารางการทบทวนครั้งถัดไปของแต่ละใบอย่างชาญฉลาด ให้คุณได้ทบทวนตอนใกล้จะลืมพอดี

คะแนนความหมายผลลัพธ์
😵 จำไม่ได้นึกไม่ออกเลยจะกลับมาเร็ว ๆ นี้
😐 ยากนึกได้ฉุกเฉินช่วงเว้นถูกสั้นลง
🙂 พอใช้นึกได้ตามปกติจัดช่วงเว้นตามมาตรฐาน
😎 ง่ายรู้ทันทีช่วงเว้นยาวขึ้นมาก
🧹 ล้างอัตโนมัติ

เมื่อคำถูกให้คะแนน 「ง่าย」ติดกันหลายครั้ง จะถูกถอดออกจากรอบทบทวนอัตโนมัติ ปรับเงื่อนไข「ล้างอัตโนมัติ」ได้ที่ การตั้งค่า → Language Made Easy

จัดการข้อมูลการ์ด

Ctrl/Cmd + P → ค้นหา「จัดการข้อมูลการ์ด」

ในหน้าจัดการคุณสามารถ:

  • 📋 กรองการ์ดตามภาษาและสถานะ
  • 🗑️ ลบการ์ดที่ไม่ต้องการเป็นชุด
  • 📤 ส่งออกข้อมูลการ์ด
💡 สองเรื่องสำคัญ

1. ข้อมูลการ์ดเก็บไว้ใน IndexedDB ในเครื่อง เวลาอัปเดตปลั๊กอินแค่เปลี่ยนสามไฟล์ main.js, manifest.json, style.css — การ์ดเดิมของคุณไม่หาย อัปเดตได้สบายใจ!

2. การ์ดรองรับ นำเข้าและส่งออกหลายรูปแบบ — txt, markdown, csv, json และอื่น ๆ — สำรองข้อมูลและย้ายถิ่นได้สะดวก

4. ใช้งานโรงฝึกแชโดว์

🎬 Language Made Easy ช่วยให้คุณเรียนจาก วิดีโอ YouTube / Bilibili ได้มีประสิทธิภาพขึ้น เก็บภาษาพูดธรรมชาติและฝึกหูไปพร้อมกัน

เปิดโรงฝึกแชโดว์

วิธีที่ 1: กดไอคอนเล่น ▶️ ในแถบข้างซ้าย
วิธีที่ 2: Ctrl/Cmd + P → ค้นหา「โรงฝึกแชโดว์」

โหลดวิดีโอ

วางลิงก์วิดีโอลงโน้ต ปลั๊กอินจะจับและโหลดให้อัตโนมัติ:

✅ วิดีโอ YouTube → วางลิงก์เพื่อโหลดอัตโนมัติ
✅ วิดีโอ Bilibili → วางลิงก์เพื่อโหลดอัตโนมัติ (ดาวน์โหลดและแคชให้อัตโนมัติ)
✅ เสียง/วิดีโอในเครื่อง → ฝังด้วย ![[video.mp4]] หรือ ![[audio.mp3]]

ดาวน์โหลดซับ

โหลดวิดีโอแล้ว กดปุ่ม 「ดาวน์โหลดซับ」 บนแถบเครื่องมือด้านขวา ปลั๊กอินจะดึงซับจาก YouTube / Bilibili แล้วแทรกลงโน้ตให้

ตัวอย่างรูปแบบซับ:

[00:12] Hello, how are you today?
[00:15] I'm fine, thank you. And you?
[01:23] What a beautiful day! Let's go for a walk.
📝 หมายเหตุ

โรงฝึกแชโดว์รองรับ รูปแบบไทม์สแตมป์หลายแบบ — จะเป็น HH:MM:SS, MM:SS หรือ [00:12] ก็จับได้หมดและโหลดให้อัตโนมัติ

ปุ่มควบคุมการเล่น

ตัวเล่นของโรงฝึกแชโดว์มีแถวปุ่มควบคุมอยู่ด้านล่าง:

ปุ่มหน้าที่หมายเหตุ
⏮️ เล่นซ้ำกระโดดไปต้นประโยคปัจจุบันฟังซ้ำจากต้นประโยค
🔁 วนซ้ำวนประโยคเดียวเหมาะกับการฝึกประโยคเดียว
▶️ / ⏸️ เล่น/หยุดควบคุมการเล่นแป้นว่าง
🐢🐇 ความเร็ว0.8x / 1.0x / 1.2xปรับตามระดับของคุณ

🎧 โหมดดิกเทชัน

อยากท้าทายการฟัง? ลอง โหมดดิกเทชัน!

แถบเครื่องมือขวาของโรงฝึกแชโดว์ → กดปุ่ม「โหมดดิกเทชัน」
→ ระบบเล่นประโยค คุณพิมพ์ตามที่ได้ยิน
→ กดส่งแล้วระบบเทียบสิ่งที่พิมพ์กับต้นฉบับ
→ จุดที่ผิดถูกมาร์กสีแดง ส่วนที่ถูกมาร์กสีเขียว

5. อัปเกรดการเรียนด้วย AI

อยากได้ประสบการณ์การเรียนที่ทรงพลังขึ้น? การตั้งค่าขั้นสูงด้านล่างจะปลดล็อกฟีเจอร์อย่าง พจนานุกรมในเครื่อง และ การวิเคราะห์ AI

5.1 ตั้งค่าพจนานุกรมในเครื่อง

พจนานุกรมในเครื่อง (รูปแบบ MDX) ให้ความหมายที่สมบูรณ์ขึ้น — มีตัวอย่างประโยค คำที่มักใช้คู่กัน คำพ้องความหมาย — แถมใช้ ออฟไลน์ได้ด้วย

การตั้งค่า → Language Made Easy → การตั้งค่าพจนานุกรม
→ ระบุพาธไฟล์พจนานุกรม MDX ในเครื่อง
→ บันทึก

5.2 พจนานุกรมในเครื่องในการใช้งานจริง

เมื่อตั้งค่าพจนานุกรมในเครื่องแล้ว ผลการค้นจะสมบูรณ์ขึ้นมาก:

ด้านพจนานุกรมออนไลน์พจนานุกรม MDX ในเครื่อง
อินเทอร์เน็ต✅ ต้องมี❌ ใช้ออฟไลน์ได้
ความละเอียดของความหมายความหมายพื้นฐานละเอียด + ตัวอย่าง + คำที่ใช้คู่กัน
ความเร็วแล้วแต่เน็ต⚡ ทันที
แหล่งที่รองรับGoogle / MyMemory / Jishoไฟล์ MDX ที่คุณเลือก

5.3 ตั้งค่า API คีย์ของโมเดลภาษาขนาดใหญ่

ฟีเจอร์วิเคราะห์ AI ต้องใช้ API คีย์ของโมเดลภาษาขนาดใหญ่ ผู้ให้บริการที่รองรับตอนนี้:

การตั้งค่า → Language Made Easy → การตั้งค่า AI
→ เลือกผู้ให้บริการโมเดล (OpenAI / Google Gemini / OpenRouter)
→ ใส่ API คีย์
→ บันทึก
💡 คำแนะนำ

- OpenAI: ใช้ได้เลยทันทีที่มีคีย์

- Google Gemini: มีช่วงใช้ฟรี เหมาะเป็นตัวสำรองหรือใช้ศึกษาเชิงลึก

5.4 ใช้งานการวิเคราะห์ AI

5.4.1 สร้างรายงานวิเคราะห์ AI

หลังโหลดซับในโรงฝึกแชโดว์แล้ว:

กดปุ่ม「วิเคราะห์ AI」บนแถบเครื่องมือด้านขวา
→ รอการวิเคราะห์เสร็จ (ปกติใช้เวลาสิบถึงยี่สิบวินาที)
→ รายงานจะแสดงในแผงด้านขวา
→ กด「บันทึกลงโน้ต」เพื่อเก็บไว้
→ กดปุ่มรูปภาพเพื่อ「บันทึกเป็นภาพยาว」ลงเครื่อง

รายงานวิเคราะห์ AI โดยทั่วไปมี:

  • 📝 คำศัพท์ — วิธีใช้และคำที่มักใช้คู่กันของคำสำคัญ
  • 🏗️ ไวยากรณ์ — แยกโครงสร้างไวยากรณ์สำคัญ
  • 🌍 เกร็ดวัฒนธรรม — บริบทวัฒนธรรมที่เกี่ยวข้อง
  • 💡 เคล็ดการเรียน — คำแนะนำเฉพาะทาง

ปลั๊กอินมาพร้อม พรอมป์วิเคราะห์ AI ในตัว 3 แบบ สำหรับความต้องการการเรียนที่ต่างกัน:

พรอมป์เหมาะกับผลลัพธ์
📝 สรุปใจความเก็บใจความของวิดีโออย่างรวดเร็วสรุปกระชับ + ประเด็นสำคัญ
📖 สองภาษาเรียนเนื้อหาทีละประโยคคำแปลสองภาษารายประโยค
🧪 ควิซสั้นทดสอบสิ่งที่เรียนไปแล้วข้อสอบที่สร้างจากวิดีโอ
💡 เขียนพรอมป์เองก็ได้ — ดู 5.4.2 เพิ่มพรอมป์แบบกำหนดเอง

5.4.2 เพิ่มพรอมป์แบบกำหนดเอง

คุณเขียนพรอมป์เองได้ ให้ AI สร้างสื่อการเรียนที่ตรงกับความต้องการของคุณ:

การตั้งค่า → Language Made Easy → การจัดการพรอมป์ AI
→ เพิ่มพรอมป์แบบกำหนดเอง
→ ตั้งชื่อและเนื้อหาพรอมป์
→ บันทึก

5.5 เติมการ์ดให้ครบด้วยคลิกเดียว

ไม่อยากพิมพ์คำอ่านกับความหมายเองตอนเพิ่มการ์ด? ใช้ เติมอัตโนมัติด้วย AI!

แผงเพิ่มการ์ด → พิมพ์คำศัพท์
→ กดปุ่ม「เติมด้วย AI」
→ คำอ่าน ความหมาย และประโยคตัวอย่างถูกเติมให้อัตโนมัติ
→ ตรวจสอบแล้วบันทึก

5.6 วิธีโหลดซับแบบอื่น

นอกจากดาวน์โหลดซับในโรงฝึกแชโดว์โดยตรง ยังมีวิธีโหลดซับแบบอื่นอีก:

5.6.1 ปุ่ม「ดาวน์โหลดซับ」ในโรงฝึกแชโดว์

ตรงที่สุด โหลดวิดีโอแล้วกดปุ่ม 「ดาวน์โหลดซับ」 บนแถบเครื่องมือด้านขวา — ปลั๊กอินจะดึงซับจาก YouTube / Bilibili ให้อัตโนมัติ

⚠️ ข้อควรรู้เรื่องดาวน์โหลดซับ

1. ปลั๊กอินดาวน์โหลดซับของ ภาษาที่เลือกไว้ตอนนี้ — กรุณาตรวจภาษาก่อนดาวน์โหลด ถ้าไม่มีซับภาษานั้น จะได้ซับเริ่มต้นของวิดีโอแทน

2. วิดีโอ Bilibili มักไม่มีซับภาษาอังกฤษ ก่อนเลือกวิดีโอ ตรวจรายการ「字幕」(ซับ) ในเครื่องเล่นของ Bilibili ว่ามีภาษาที่คุณต้องการหรือไม่

5.6.2 ใช้ Obsidian Web Clipper

ด้วยส่วนขยายเบราว์เซอร์ Obsidian Web Clipper คุณเก็บซับ YouTube เข้าโน้ต Obsidian ได้ระหว่างดูวิดีโอเลย

ติดตั้งส่วนขยายเบราว์เซอร์ Obsidian Web Clipper
→ ที่หน้าวิดีโอ YouTube กดไอคอนส่วนขยาย
→ เลือกเก็บเนื้อหาซับ
→ จะถูกบันทึกเป็นโน้ตพร้อมไทม์สแตมป์อัตโนมัติ

5.6.3 ใช้ปลั๊กอิน ytranscript

ytranscript อีกหนึ่งปลั๊กอิน Obsidian ที่ช่วยดาวน์โหลดซับ YouTube ใน Obsidian:

ค้นหาและติดตั้ง「ytranscript」จากปลั๊กอินชุมชนของ Obsidian
→ เรียกใช้ ytranscript จากแถบคำสั่งเพื่อดึงซับ YouTube
→ ซับจะถูกแทรกลงโน้ตพร้อมไทม์สแตมป์
→ เปิดโรงฝึกแชโดว์แล้วเริ่มใช้งานได้เลย

5.6.4 โหลดไฟล์ SRT สำหรับวิดีโอในเครื่อง

ถ้าคุณมีไฟล์วิดีโอในเครื่องและไฟล์ซับ SRT ที่คู่กัน:

วิธีที่ 1: คัดลอกเนื้อหา SRT ลงโน้ต
         → ตรวจว่ารูปแบบไทม์สแตมป์ SRT ถูกต้อง
         → ฝังวิดีโอในโน้ตด้วย ![[video.mp4]]
         → เปิดโรงฝึกแชโดว์เพื่อแยกวิเคราะห์วิดีโอและซับ

วิธีที่ 2: วางไฟล์ SRT ไว้ข้างไฟล์วิดีโอในคลัง
         → ฝังวิดีโอในโน้ตด้วย ![[video.mp4]]
         → ปลั๊กอินจับคู่ไฟล์ SRT ชื่อเดียวกันให้อัตโนมัติ

6. การใช้งานเพิ่มเติม

6.1 คำสั่งด่วน: สลับธีมคลิกเดียว

ปลั๊กอินมาพร้อม 10 ธีมที่ออกแบบมาอย่างดี เพื่อให้สภาพแวดล้อมการเรียนน่าใช้:

Ctrl/Cmd + P → ค้นหา「สลับไปธีมถัดไป」
→ กดแต่ละครั้งจะสลับไปธีมถัดไป
ธีมสไตล์
📜 Paper Inkหมึกบนกระดาษคลาสสิก อบอุ่นนุ่มนวล
🌿 Mint Atelierความสดชื่นมินต์ สะอาดเป็นมืออาชีพ
🌸 Rose Blushชมพูกุหลาบอ่อน นุ่มนวลโรแมนติก
💜 Lavender Dreamความฝันลาเวนเดอร์ เบาสบาย
🍬 Candy Popปาร์ตี้ลูกกวาด สดใสมีชีวิตชีวา
🌳 Mindful Oasisโอเอซิสแห่งสติ เป็นธรรมชาติอบอุ่น
🪸 Coral Warmthอุ่นไอปะการัง อบอุ่นมีพลัง
🌊 Ocean Glassดวงใจมหาสมุทร ลึกและสงบ
🌌 Aurora Prismปริซึมแสงเหนือ ลึกลับหลากสี
🍋 Dark Lemonเลมอนยามค่ำ มืดเย็นสบาย

6.2 คำสั่งด่วน: สลับภาษาเรียนคลิกเดียว

เรียนหลายภาษาอยู่? สลับไปมาได้อย่างรวดเร็ว:

Ctrl/Cmd + P → ค้นหา「สลับไปอังกฤษ / เยอรมัน / ฝรั่งเศส / ...」
→ ภาษาเรียนปัจจุบันสลับทันที

6.3 คำสั่งด่วน: รายงานวิเคราะห์ AI

Ctrl/Cmd + P → ค้นหา「วิเคราะห์ AI」
→ เลือกโน้ตใดก็ได้ในคลังมาวิเคราะห์ด้วย AI

6.4 ตั้งพาธบันทึกสมุดคำศัพท์

ทุกครั้งที่เพิ่มคำเข้าสมุดคำศัพท์ ปลั๊กอินจะสร้างไฟล์สมุดคำศัพท์ Markdown ในคลัง คุณปรับตำแหน่งบันทึกได้:

การตั้งค่า → Language Made Easy → การตั้งค่าสมุดคำศัพท์
→ ระบุพาธและชื่อไฟล์สมุดคำศัพท์
→ บันทึก

6.5 ตั้งพาธบันทึกรายงานวิเคราะห์ AI

รายงานวิเคราะห์ AI บันทึกไว้ที่อื่นได้เช่นกัน:

การตั้งค่า → Language Made Easy → การตั้งค่าการวิเคราะห์ AI
→ ระบุพาธบันทึกรายงาน
→ บันทึก

7. คำถามที่พบบ่อย

❓ ค้นคำแล้วไม่ตอบสนอง?

กรุณาตรวจดังนี้:

1. ตรวจว่าตั้งค่าพจนานุกรมเรียบร้อยแล้ว (พจนานุกรมออนไลน์ต้องต่ออินเทอร์เน็ต)

2. ถ้าใช้พจนานุกรม MDX ตรวจว่าพาธไฟล์ mdx, mdd, css กรอกถูกต้องในการตั้งค่า

3. ตรวจว่าภาษาเรียนปัจจุบันตั้งค่าถูกต้อง

❓ ทำไมไม่เห็นการ์ดที่เพิ่งเพิ่ม?

การ์ดที่เพิ่มใหม่จะอยู่ท้ายสุดของคิวการทบทวน

❓ วิดีโอ Bilibili ดาวน์โหลดได้แต่ซับจีน?

ตรวจดูว่าวิดีโอมีซับภาษาอื่นอัปโหลดจริงหรือไม่ ซับสองภาษาที่พิมพ์ติดภาพในเฟรมไม่ได้แปลว่าผู้อัปโหลดให้ไฟล์ซับภาษานั้นมาด้วย

❓ โรงฝึกแชโดว์ขึ้นให้「ล็อกอิน」ตอนเปิดวิดีโอ YouTube?

เปลี่ยนเครือข่ายมักช่วยแก้ได้ ปกติเกี่ยวข้องกับสภาพแวดล้อมเครือข่ายปัจจุบัน — ลองเปลี่ยนโหนดเครือข่ายแล้วลองใหม่

❓ วิเคราะห์ AI ขึ้น error?

กรุณาตรวจ:

1. ตั้งค่า API คีย์ถูกต้องหรือไม่?

2. อินเทอร์เน็ตใช้งานปกติหรือไม่?

3. ยอดเงินใน API เพียงพอหรือไม่?
