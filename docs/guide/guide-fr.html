Language Made Easy · Guide d’utilisation

Plugin Obsidian immersif d’apprentissage des langues · Recherche / Cartes / Shadowing / IA

InstallerRechercheCartesShadowingIAPlusFAQ

Language Made Easy est un plugin Obsidian qui intègre recherche de mots, cartes mémoire, shadowing vidéo et analyse IA dans votre flux de prise de notes — vous apprenez une langue naturellement en lisant, en regardant et en notant.

1. Installer le plugin

📦 Télécharger & installer

  1. Copiez les fichiers du plugin (main.js, manifest.json, style.css) dans le dossier des plugins de votre coffre Obsidian :
votre-coffre/
└── .obsidian/
    └── plugins/
        └── language-made-easy/
            ├── main.js
            ├── manifest.json
            └── style.css
💡 Comment trouver le dossier des plugins ?

Dans Obsidian, ouvrez Paramètres → Extensions communautaires → cliquez sur l’icône 📁 pour aller directement au dossier des plugins.

  1. De retour dans Obsidian : Paramètres → Extensions communautaires, cherchez Language Made Easy et activez-le.

🆓 Essai gratuit de 3 jours → Édition complète

Votre essai gratuit de 3 jours démarre au premier lancement — toutes les langues sont ouvertes à l’apprentissage (recherche / cartes / shadowing / analyse IA) avec les fonctions de base ; le compte à rebours est dans la barre d’état.

À la fin de l’essai, continuez avec l’Édition complète (achat unique, mises à jour à vie). Elle déverrouille tous les modules avancés :

  • 7 langues de plus : anglais / allemand / français / espagnol / coréen / russe / japonais
  • Cartes illimitées, 5 dictionnaires locaux, dictionnaires hors ligne mobiles
  • Synchronisation des cartes entre appareils, import / export de données
  • Génération de cartes par lot par IA, export des rapports IA
  • 9 thèmes d’interface supplémentaires, modes de révision écoute / saisie
  • Marque-pages vidéo, cartes pédagogiques vidéo, téléchargements en un clic & par lot depuis la page d’abonnements

🌐 Visitez https://languagemadeeasy.com pour obtenir l’Édition complète.

2. Utiliser la recherche de mots

📖 Voici un passage anglais d’exemple :

The best way to learn a new language is not through memorization, but through immersion. When you read, listen, and speak in context, your brain absorbs vocabulary and grammar naturally — just like how you learned your first language as a child.

Essayez de double-cliquer sur un mot inconnu du passage ci-dessus pour tester la recherche !

Ouvrir l’assistant de mots

Plusieurs façons :

Option 1 : cliquez sur l’icône 📖 dans la barre latérale gauche

3. Ajouter et gérer des cartes

🎴 Une fois que vous avez accumulé des mots nouveaux en lisant et en cherchant, voici comment les réviser systématiquement :

Cartes générées automatiquement

Quand vous cliquez sur « Ajouter au carnet » après une recherche, le plugin génère automatiquement une carte. Chaque carte comprend :

  • ✅ Mot + phonétique
  • ✅ Définition
  • ✅ Contexte du mot (la phrase de la note où vous l’avez cherché)
  • ✅ Lien vers la note source
  • ✅ Date d’ajout

Ajouter une carte manuellement

Ouvrez le panneau de révision → cliquez sur « Ajouter une carte » en bas
→ Renseignez mot, phonétique (facultatif), définition, phrase d’exemple (facultatif)
→ Enregistrer

Commencer la révision

Ouvrez le panneau de révision :

Option 1 : cliquez sur l’icône 🧠 dans la barre latérale gauche
Option 2 : Ctrl/Cmd + P → cherchez « Commencer la révision des cartes »

Déroulement

👀 Voir le recto → 🤔 Essayer de rappeler le sens
→ 🖱️ Cliquer pour retourner et révéler la définition → ⭐ Noter votre mémorisation

Échelle de notation

🧠 À propos de l’algorithme FSRS

La révision repose sur l’algorithme FSRS (répétition espacée moderne). Selon vos notes, il planifie intelligemment la prochaine révision de chaque carte, juste à la limite de l’oubli.

NoteSensEffet
😵 RepasserPas rappelé du toutReviendra bientôt
😐 DifficileÀ peine rappeléIntervalle raccourci
🙂 BienRappelé normalementIntervalle standard
😎 FacileSu immédiatementIntervalle très allongé
🧹 Nettoyage automatique

Après plusieurs « Facile », un mot quitte automatiquement la rotation de révision. Vous pouvez personnaliser le déclencheur dans Paramètres → Language Made Easy.

Gérer les données des cartes

Ctrl/Cmd + P → cherchez « Gérer les données des cartes »

Dans le gestionnaire, vous pouvez :

  • 📋 Filtrer les cartes par langue et statut
  • 🗑️ Supprimer en lot les cartes devenues inutiles
  • 📤 Exporter vos données de cartes
💡 Deux remarques importantes

1. Les données des cartes sont dans l’IndexedDB local. Pour mettre à jour le plugin, remplacez simplement les trois fichiers main.js, manifest.json et style.css — vos cartes existantes ne sont pas affectées. Mettez à jour en confiance !

2. Les cartes gèrent l’import et l’export en plusieurs formats — txt, markdown, csv, json, etc. — pour sauvegarder et migrer facilement.

4. L’atelier de shadowing

🎬 Language Made Easy vous aide à apprendre plus efficacement avec des vidéos YouTube / Bilibili, pour un langage parlé naturel et une meilleure écoute.

Ouvrir l’atelier

Option 1 : cliquez sur l’icône ▶️ dans la barre latérale gauche
Option 2 : Ctrl/Cmd + P → cherchez « Atelier de shadowing »

Charger une vidéo

Collez un lien vidéo dans une note — le plugin le reconnaît et le charge automatiquement :

✅ Vidéo YouTube → collez le lien, chargement auto
✅ Vidéo Bilibili → collez le lien, chargement auto (téléchargée & en cache)
✅ Audio/vidéo local → intégrez avec ![[video.mp4]] ou ![[audio.mp3]]

Télécharger les sous-titres

Après le chargement, cliquez sur « Télécharger les sous-titres » dans la barre d’outils droite. Le plugin récupère les sous-titres de YouTube / Bilibili et les insère dans votre note.

Exemple de format :

[00:12] Hello, how are you today?
[00:15] I'm fine, thank you. And you?
[01:23] What a beautiful day! Let's go for a walk.
📝 Remarque

L’atelier accepte plusieurs formats d’horodatage — HH:MM:SS, MM:SS ou [00:12], tous sont reconnus et chargés automatiquement.

Contrôles de lecture

Le lecteur de l’atelier propose une rangée de contrôles en bas :

BoutonFonctionUsage
⏮️ RejouerRetour au début de la phraseRéécouter depuis le début
🔁 RépéterBoucle sur une phraseParfait pour bosser une phrase
▶️ / ⏸️ Lecture/PauseContrôler la lectureBarre d’espace
🐢🐇 Vitesse0,8x / 1,0x / 1,2xAjustez selon votre niveau

🎧 Mode dictée

Envie de challenger votre écoute ? Essayez le mode dictée !

Barre d’outils droite → cliquez sur « Mode dictée »
→ Une phrase joue, vous tapez ce que vous entendez
→ À l’envoi, votre saisie est comparée à l’original
→ Erreurs en rouge, correct en vert

5. Passer au niveau supérieur avec l’IA

Envie d’une expérience plus puissante ? Les réglages avancés ci-dessous déverrouillent les dictionnaires locaux et l’analyse IA.

5.1 Configurer un dictionnaire local

Un dictionnaire local (format MDX) donne des définitions plus riches — exemples, collocations, synonymes — même hors ligne.

Paramètres → Language Made Easy → Réglages du dictionnaire
→ Définissez le chemin de votre dictionnaire MDX local
→ Enregistrer

5.2 Le dictionnaire local en action

Avec un dictionnaire local, les résultats deviennent bien plus riches :

AspectDictionnaire en ligneMDX local
Réseau✅ Requis❌ Fonctionne hors ligne
Détail des définitionsDéfinitions basiquesDétaillées + exemples + collocations
VitesseSelon le réseau⚡ Instantané
SourcesGoogle / MyMemory / JishoFichiers MDX personnalisés

5.3 Configurer une clé API LLM

L’analyse IA nécessite une clé API de grand modèle de langage. Fournisseurs pris en charge :

Paramètres → Language Made Easy → Réglages IA
→ Choisissez un fournisseur (OpenAI / Google Gemini / OpenRouter)
→ Saisissez votre clé API
→ Enregistrer
💡 Recommandations

- OpenAI : saisissez la clé API et c’est parti.

- Google Gemini : offre gratuite disponible ; parfait en secours ou pour l’approfondissement.

5.4 Utiliser l’analyse IA

5.4.1 Générer un rapport d’analyse IA

Après avoir chargé des sous-titres dans l’atelier :

Cliquez sur « Analyse IA » dans la barre d’outils droite
→ Attendez la fin de l’analyse (dix à vingt secondes en général)
→ Le rapport s’affiche dans le panneau droit
→ « Enregistrer dans la note » pour le conserver
→ Le bouton image permet de « Sauver en image longue »

Un rapport d’analyse IA comprend généralement :

  • 📝 Vocabulaire — emploi et collocations des mots clés
  • 🏗️ Grammaire — décorticage des structures clés
  • 🌍 Culture — contexte culturel pertinent
  • 💡 Conseils — suggestions d’apprentissage ciblées

Le plugin embarque 3 prompts d’analyse intégrés selon vos besoins :

PromptIdéal pourRésultat
📝 RésuméSaisir vite l’essentielRésumé concis + points clés
📖 BilingueÉtudier ligne à ligneTraduction bilingue phrase par phrase
🧪 Mini-quizTester vos acquisQuestions générées depuis la vidéo
💡 Vous pouvez écrire vos propres prompts — voir 5.4.2 Ajouter un prompt personnalisé.

5.4.2 Ajouter un prompt personnalisé

Rédigez vos prompts et laissez l’IA produire du matériel sur mesure :

Paramètres → Language Made Easy → Gestion des prompts IA
→ Ajouter un prompt personnalisé
→ Définissez nom et contenu
→ Enregistrer

5.5 Remplissage automatique des cartes

Pas envie de saisir phonétique et définitions à la main ? Utilisez le remplissage IA !

Pan « Ajouter une carte » → saisissez le mot
→ Cliquez sur « Remplissage IA »
→ Phonétique, définition et exemple sont remplis automatiquement
→ Vérifiez et enregistrez

5.6 Autres façons de charger des sous-titres

Hormis le téléchargement direct dans l’atelier, il existe d’autres méthodes :

5.6.1 Le bouton « Télécharger les sous-titres » de l’atelier

La méthode la plus directe. Après le chargement, cliquez sur « Télécharger les sous-titres » — le plugin les récupère automatiquement de YouTube / Bilibili.

⚠️ Remarques sur le téléchargement

1. Le plugin télécharge les sous-titres de la langue d’étude sélectionnée — vérifiez la langue avant. Si aucun sous-titre n’existe dans cette langue, les sous-titres par défaut de la vidéo sont renvoyés.

2. Les vidéos Bilibili n’ont souvent pas de sous-titres anglais. Avant de choisir, vérifiez la liste « 字幕 » (sous-titres) du lecteur Bilibili.

5.6.2 Obsidian Web Clipper

Avec l’extension Obsidian Web Clipper, clippez les sous-titres YouTube directement dans une note pendant le visionnage :

Installez l’extension Obsidian Web Clipper
→ Sur la page YouTube, cliquez sur l’icône de l’extension
→ Choisissez de clipper les sous-titres
→ Sauvegardé automatiquement en note horodatée

5.6.3 Le plugin ytranscript

ytranscript est un autre plugin Obsidian pour télécharger les sous-titres YouTube :

Cherchez et installez « ytranscript » dans les extensions communautaires
→ Utilisez ytranscript depuis la palette de commandes
→ Les sous-titres sont insérés avec horodatage
→ Ouvrez l’atelier pour commencer

5.6.4 Charger des fichiers SRT pour vidéos locales

Si vous avez une vidéo locale et le fichier SRT correspondant :

Option 1 : copiez le contenu du SRT dans une note
         → Vérifiez le format des horodatages
         → Intégrez la vidéo avec ![[video.mp4]]
         → Ouvrez l’atelier pour analyser vidéo et sous-titres

Option 2 : placez le SRT à côté de la vidéo dans le coffre
         → Intégrez la vidéo avec ![[video.mp4]]
         → Le plugin associe automatiquement le SRT homonyme

7. FAQ

❓ La recherche ne réagit pas ?

Vérifiez :

1. Un dictionnaire est bien configuré (les dictionnaires en ligne exigent le réseau).

2. Avec un MDX, contrôlez les chemins mdx, mdd et css dans les réglages.

3. La langue d’étude actuelle est correcte.

❓ Je ne vois pas la carte que je viens d’ajouter ?

Les nouvelles cartes arrivent tout à la fin de la file de révision.

❓ Bilibili ne télécharge que des sous-titres chinois ?

Vérifiez que la vidéo propose réellement des sous-titres dans d’autres langues. Des sous-titres bilingues incrustés à l’écran ne signifient pas que l’auteur a fourni ces fichiers.

❓ L’atelier me demande de « me connecter » pour une vidéo YouTube ?

Changer de réseau règle souvent le souci. C’est lié à votre environnement réseau — essayez un autre nœud.

❓ L’analyse IA renvoie une erreur ?

Vérifiez :

1. La clé API est-elle correctement configurée ?

2. Votre connexion fonctionne-t-elle ?

3. Le solde API est-il suffisant ?
