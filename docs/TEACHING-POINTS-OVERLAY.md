# 教学点浮层（Teaching Points Overlay）—— 功能文档

> 状态：**已实现**（v1）。最近更新：2026-07-13

视频播放到标记为关键语言点的字幕块时：播完整句 → 自动暂停 → 视频右下角弹出玻璃拟态学习卡 → 讲解 / 做题 → 按策略自动或手动续播。纯增量功能，仅在笔记里写了特定 marker 时触发，不影响任何既有流程。

## 触发 marker

| 开标记 | 闭合 | 说明 |
|---|---|---|
| `【小课堂】` | `::` | 主用，中文友好 |
| `::teach` | `::` | 兼容旧写法 |

两种写法都支持**内联**（marker 贴字幕行尾、`::` 贴教学末行尾）或**独占行**。marker 紧跟某条 `[MM:SS]` 字幕块，即把该块标为关键点。

## 内容格式

`【小课堂】 ... ::` 块内可混排：**markdown 讲解** + **互动题**（单选 / 多选 / 判断）。解析器对前导空白/缩进容错。

**讲解**：普通 markdown（`**加粗**`、列表、代码）。

**单选**（默认）
```
? 题干
- 选项A
- 选项B
答: 正确项
```

**多选** —— `?多选:` 开头，`答:` 逗号/顿号列多个
```
?多选: 题干
- 选项A
- 选项B
- 选项C
答: 选项A, 选项C
```

**判断** —— `?判断:` 开头，`答: 对` / `答: 错`（也认 true/false/T/F/是/否/✓/✗）
```
?判断: 陈述句
答: 错
```

题标记：`?` / `?多选:` / `?判断:`；选项行首 `-`（也支持 `* + ＋ －`）；答案 `答:` / `答案:` / `answer:`。一块可多题、可与讲解混排。

## 续播策略（设置可调）

设置项（视频区段下）：
- **教学点自动续播**（`teachingAutoContinue`，默认开）
- **讲解卡倒计时秒数**（`teachingCountdownSec`，默认 8）

开启时按卡片类型分策略：
- **纯讲解卡**（无题）→ 弹出后显倒计时，到 0 自动续播；任何手动交互（✕ / 继续 / 重放）取消倒计时。
- **题卡** → **答对**后 ~1.2s 自动续播（让看到绿色反馈）；答错停留，手动继续（强制看正解）；多选须全对才触发。
- 关闭开关 → 回到纯手动（点「继续播放」才走）。

每张卡底部有「重放」（回块首重播，结束再弹题）和「继续播放」。

## 触发时机

进入带教学标记的块后，**播到块末（`currentTime >= endSec`）才暂停弹卡**（不是一进块就停），并抑制影子/听写模式自带的末尾暂停，确保整句播完。本轮每块只弹一次；时间回跳（重播/rewind/seek 回去）清空"已弹"集合，重放会再弹。
