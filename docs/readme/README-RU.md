# Language Made Easy — иммерсивное рабочее пространство для изучения английского в Obsidian

> 🌐 Другие языки: [English](./README-EN.md) · [简体中文](../../README.md) · [繁體中文](./README-ZH-TW.md) · [Deutsch](./README-DE.md) · [Français](./README-FR.md) · [Español](./README-ES.md) · [日本語](./README-JA.md) · [한국어](./README-KO.md) · Русский · [ไทย](./README-TH.md)

**Language Made Easy (LME)** превращает ваше хранилище Obsidian в полноценное иммерсивное пространство для изучения английского: мгновенный поиск слов прямо во время чтения, интервальные карточки по алгоритму FSRS, шэдоуинг (повторение за диктором) с синхронизированными субтитрами и анализ с помощью ИИ — всё в одном месте, и всё хранится в виде обычных заметок в вашем хранилище.

Ссылки на покупку показываются в диалоге обновления внутри плагина. Различия см. в [сравнении функций](#-free-basic-vs-full-edition) ниже.
>
> **Базовое издание охватывает весь ежедневный учебный цикл — поиск слов, повторение карточек, шэдоуинг и видеозаметки; расширенные возможности, такие как больше языков, синхронизация между устройствами и пакетная обработка, входят в Полное издание.**

## ✨ Все функциональные модули

### 🎬 Видеозаметки в один клик — от ссылки до заметки, готовой к шэдоуингу, за один шаг
Вставьте ссылку на YouTube / Bilibili, и плагин получит название, канал и обложку, создаст структурированную заметку с субтитрами и скачает субтитры — можно заниматься шэдоуингом в любой момент. Три точки входа:
- **Панель навигации**: кнопка «Создать видеозаметку» рядом со строкой поиска
- **Мастерская шэдоуинга**: нажмите значок мастерской на левой панели и вставьте ссылку в поле ввода
- **Страница подписок YouTube**: создавайте заметки для любого видео прямо при просмотре ленты, **с пакетным скачиванием для нескольких выбранных видео** (Полное издание)

### 📖 Словарный помощник — читайте что угодно, узнавайте значения мгновенно
- **Мгновенный поиск**: `Ctrl/Cmd + двойной клик` по любому слову (или выделите текст) — определения тут же появляются в боковой панели
- **Захват контекста**: полное предложение, содержащее слово, автоматически сохраняется как пример его употребления
- **Офлайн-словари MDX**: подключайте локальные словари `.mdx`/`.mdd` на компьютере без ограничений по количеству (импорт на мобильных устройствах — в Полном издании)
- **Цепочка онлайн-источников**: Youdao → Google Translate → MyMemory, все сервисы бесплатные и публичные, ключ не нужен
- **Произношение**: воспроизведение звука с умной предварительной загрузкой
- **Добавление в один клик** в ваш словарный блокнот (IndexedDB + автоматически поддерживаемый markdown-файл)

### 🧠 Карточки FSRS — запоминайте то, что выучили
- Передовой **планировщик FSRS** (`ts-fsrs`) вычисляет оптимальные интервалы повторения для каждой карточки
- **Режим изучения с переворотом карточек** с плавными анимациями и звуком перелистывания страниц
- **Панель роста**: годовая карта активности, статистика повторений, ежедневное напоминание о повторении
- **Менеджер карточек**: поиск, фильтрация по языку/уровню освоения, сортировка, редактирование на месте, массовое удаление
- **Питомец-спутник для обучения** 🐣: маленький компаньон, который вылупляется, растёт и развивается вместе с вашими учебными сериями

### 🎬 Мастерская шэдоуинга — учитесь на настоящих видео
- **YouTube, Bilibili и локальные видео/аудио** файлы в одном рабочем пространстве
- **Создание видеозаметки по ссылке** со скачиванием субтитров в неё — занимайтесь офлайн в любое время

- **Страница каталога мастерской**: все ваши заметки с субтитрами организованы с сортировкой, фильтрацией и группировкой

### ✨ Анализ с помощью ИИ — используйте свой API-ключ
- **6 встроенных шаблонов анализа**: комплексный анализ, сложность лексики, культурный контекст, двуязычное детальное чтение, тест на понимание прочитанного и задание с пропусками
- **Кликабельные метки времени** в каждом отчёте — мгновенный переход к нужному моменту видео
- **История и каталог отчётов**: просматривайте, ищите, группируйте и открывайте прошлые отчёты
- **Оценка произношения ИИ** по записям шэдоуинга
- **Автозаполнение карточек в один клик**: позвольте ИИ дополнить недостающие поля на ваших карточках
- Работает с **OpenAI, DeepSeek, Google Gemini, Kimi, GLM, Qwen, OpenRouter или любым совместимым с OpenAI endpoint** — ваш ключ, ваш выбор, ваши данные

## 🚀 Установка

**Из каталога сообщества Obsidian (рекомендуется)**: Настройки → Сторонние плагины → Обзор → найдите «Language Made Easy» → Установить → Включить.

**Вручную**: скачайте `main.js`, `manifest.json` и `styles.css` из последнего [релиза](https://github.com/PandoraReads/language-made-easy-lite/releases) в папку `.obsidian/plugins/language-made-easy/`, затем включите плагин в Настройки → Сторонние плагины.

### Первые шаги
1. **Функции ИИ (необязательно)** — добавьте LLM-провайдера со своим API-ключом в настройках плагина (OpenAI / DeepSeek / Gemini / Kimi / GLM / Qwen / OpenRouter / другой совместимый с OpenAI)
2. **Словари (необязательно)** — зарегистрируйте локальные словари MDX или положитесь на бесплатную онлайн-цепочку
3. **Словарный блокнот** — выберите папку для автоматически поддерживаемого файла словаря
4. Нажмите значок выпускной шапочки на панели, чтобы открыть **панель навигации**, и начните исследование

## 🌐 Использование сети

Плагин полностью работает офлайн, за исключением следующих необязательных запросов, инициируемых пользователем:

- **Словарь / перевод / произношение**: `dict.youdao.com`, `translate.googleapis.com` / `translate.google.com`, `dict.iciba.com`, `api.mymemory.translated.net`
- **Видео и субтитры** (когда вы открываете/скачиваете видео или обновляете подписки): `www.youtube.com`, `i.ytimg.com` / `img.youtube.com`, `api.bilibili.com`, `www.bilibili.com`, `b23.tv`; на мобильных устройствах встраивание YouTube переключается на официальный прокси Obsidian `releases.obsidian.md`
- **Функции ИИ** (только если вы настроили провайдера): endpoint выбранного вами провайдера, запросы выполняются с **вашим собственным API-ключом**
- Словари MDX — это локальные файлы, ничего не скачивается

## 🔒 Приватность

- **Никакой телеметрии, никакой аналитики, никаких аккаунтов**
- Единственные данные, покидающие ваше устройство, — это выполненные вами поисковые запросы/переводы и ИИ-провайдеры, настроенные **вами**

**Файлы вне хранилища**: настройки словарей могут указывать на MDX-файлы, хранящиеся в другом месте на вашем устройстве; плагин читает только файлы, которые вы явно выбрали.

## 📋 История изменений

### 4.2.0

- **Интерфейс на 10 языках** — английский, упрощённый/традиционный китайский, немецкий, французский, испанский, японский, корейский, русский и тайский. По умолчанию интерфейс следует языку Obsidian, и его можно переопределить в настройках; открытые представления перерисовываются сразу после переключения.
- **Локализованные ИИ-отчёты** — добавлены варианты промптов на английском, а отчёты пишутся на языке интерфейса при не-китайском интерфейсе.
- **Более умная цепочка перевода** — целевые языки перевода следуют языку интерфейса, а для неанглийских изучаемых языков по умолчанию используется Google Translate.
- **Локализованный процесс покупки** — при не-китайском интерфейсе диалог обновления открывает официальный сайт.
- **Многоязычное встроенное руководство** — HTML-руководство поставляется на всех 10 языках интерфейса.
- **Доработка панели навигации** — блоки статистики и кнопки быстрых действий адаптируются к языкам с длинными словами: числа выравниваются в одну строку, подписи никогда не переносятся и не накладываются, а текст кнопок ограничен двумя строками.
- **Полностью скрытые полосы прокрутки** на панели навигации и в представлениях повторения карточек.
- Двуязычное описание плагина (английский + китайский) в манифесте и двуязычное вступление в китайском README.
