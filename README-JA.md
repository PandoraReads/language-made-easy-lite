# Language Made Easy — 没入型の Obsidian 英語学習ワークスペース

> 🌐 その他の言語: [English](./README-EN.md) · [简体中文](./README.md) · [繁體中文](./README-ZH-TW.md) · [Deutsch](./README-DE.md) · [Français](./README-FR.md) · [Español](./README-ES.md) · 日本語 · [한국어](./README-KO.md) · [Русский](./README-RU.md) · [ไทย](./README-TH.md)

**Language Made Easy (LME)** は、Obsidian のヴォールトを完全な没入型英語学習ワークスペースに変えます。読書中の即時辞書引き、FSRS 分散学習フラッシュカード、同期字幕付きのシャドーイング練習、AI による解析まで、すべてを 1 か所に。すべてのデータはプレーンなノートとしてヴォールト内に保存されます。

<p align="center"><img src="./assets/screenshots/hero-overview.png" width="640" alt="ワンストップの語学学習ソリューション"></p>


> ### 💡 フリーミアムについて
> 本プラグインの基本機能は無料でインストール・利用できます。高度な機能は、フルエディション（買い切り・一回の購入で今後のすべてのアップデートに永久アクセス）で完全にアンロックされます。アップグレードダイアログに購入リンクが表示されます。違いについては、下記の[機能比較表](#-free-basic-vs-full-edition)をご覧ください。
>
> **ベーシックエディションは日常の学習ループ全体（辞書引き・フラッシュカード復習・シャドーイング・動画ノート）をカバーします。多言語対応、デバイス間同期、一括処理などの高度な機能はフルエディションに搭載されています。**

## ✨ 全機能モジュール

### 🎬 ワンクリック動画ノート — リンクからシャドーイング準備完了のノートまで一瞬で
YouTube / Bilibili のリンクを貼り付けるだけで、タイトル・チャンネル・サムネイルを取得し、構造化された字幕ノートを作成、字幕をダウンロードします。いつでもシャドーイングできる状態に。エントリーポイントは 3 つ:
- **ナビゲーションパネル**: 検索ボックスの横にある「動画ノートを生成」ボタン
- **シャドーイング工房**: 左リボンの工房アイコンをクリックし、入力ボックスにリンクを貼り付けて解析
- **YouTube 登録チャンネルページ**: フィードを閲覧しながら任意の動画のノートを生成、**複数選択の一括ダウンロード対応**（フルエディション）

<p align="center"><img src="./assets/screenshots/video-note.png" width="640" alt="生成された動画ノート"></p>

<p align="center"><img src="./assets/screenshots/nav-video-note.gif" width="640" alt="ナビゲーションパネルに動画リンクを入力してワンクリックで動画ノートを生成"></p>

**ノートを一元管理**: すべての動画ノートは工房のカタログページに集約され、並べ替え・フィルター・グループ化に対応。カードをクリックするとシャドーイングを開始、Shift+クリックでノートをプレビューできます。

### 📖 辞書アシスタント — 何でも読みながら、すぐに調べる
- **即時検索**: 任意の単語を `Ctrl/Cmd + ダブルクリック`（またはテキスト選択）— 定義がサイドバーに即座に表示されます
- **文脈キャプチャ**: 単語を含む全文が自動的に例文として保存されます
- **オフライン MDX 辞書**: デスクトップではローカルの `.mdx`/`.mdd` 辞書を個数制限なしで読み込み可能（モバイルでのインポートはフルエディション）
- **オンラインフォールバックチェーン**: Youdao → Google 翻訳 → MyMemory、すべて無料の公開 API、キー不要
- **発音**: スマートプリロード付きの音声再生
- **ワンクリックで単語帳に追加**（IndexedDB + 自動管理の markdown ファイル）

<p align="center"><img src="./assets/screenshots/dictionary-lookup.png" width="640" alt="ダブルクリック検索とサイドバーの定義表示"></p>

### 🧠 FSRS フラッシュカード — 学んだことを忘れない
- 最先端の **FSRS スケジューラ**（`ts-fsrs`）が各カードに最適な復習間隔を計算
- カードがめくれるアニメーションとページめくり音が心地よい**フリップ学習モード**
- **成長ダッシュボード**: 年間ヒートマップ、復習統計、毎日の復習リマインダー
- **フラッシュカードマネージャー**: 検索、言語/習熟度によるフィルター、並べ替え、インライン編集、一括削除
- **学習コンパニオンペット** 🐣: 継続日数とともに孵化し、レベルアップして成長していく小さな相棒

### 🎬 シャドーイング工房 — 実際の動画から学ぶ
- **YouTube・Bilibili・ローカルの動画/音声**ファイルを 1 つのワークスペースで
- **URL から動画ノートを生成**し、字幕をダウンロード、いつでもオフラインで練習
- **リアルタイム字幕同期**、再生中は自動スクロール
- **シャドーイングモード & ディクテーションモード** — リピートして発音するモードと聞いて書き取るモードをワンクリックで切り替え
- **精密な再生コントロール**: 0.8 倍 / 1.0 倍 / 1.25 倍速、-5 秒 / -10 秒のクイックジャンプ
- **工房カタログページ**: すべての字幕ノートを並べ替え・フィルター・グループ化して整理

### ✨ AI 解析 — API キーは自分のものを
- **内蔵の 6 種類の解析テンプレート**: 総合解析、語彙難易度、文化的背景、日英対訳精読、リーディングクイズ、空所補充チャレンジ
- 各レポートの**タイムスタンプをクリック可能** — 動画の該当シーンにすぐにジャンプ
- **レポート履歴 & カタログ**: 過去のレポートを閲覧・検索・グループ化・再オープン
- シャドーイングの録音に対する **AI 発音スコアリング**
- **ワンクリックのフラッシュカード自動入力**: 不足している項目を AI が補完
- **OpenAI、DeepSeek、Google Gemini、Kimi、GLM、Qwen、OpenRouter、または OpenAI 互換の任意のエンドポイント**に対応 — キーも選択もデータも、すべてあなたのもの

## 🚀 インストール

**Obsidian コミュニティディレクトリから（推奨）**: 設定 → コミュニティプラグイン → 参照 → 「Language Made Easy」を検索 → インストール → 有効化。

**手動**: 最新の [リリース](https://github.com/PandoraReads/language-made-easy-lite/releases) から `main.js`、`manifest.json`、`styles.css` をダウンロードし、`.obsidian/plugins/language-made-easy/` に配置して、設定 → コミュニティプラグインでプラグインを有効化してください。

### はじめに
1. **AI 機能（任意）** — プラグイン設定で自分の API キーを使って LLM プロバイダーを追加（OpenAI / DeepSeek / Gemini / Kimi / GLM / Qwen / OpenRouter / OpenAI 互換のカスタムエンドポイント）
2. **辞書（任意）** — ローカルの MDX 辞書を登録するか、無料のオンラインチェーンを利用
3. **単語帳** — 自動管理される単語ファイルの保存先フォルダを選択
4. 卒業帽のリボンアイコンをクリックして**ナビゲーションパネル**を開き、いろいろ試してみてください

## 🌐 ネットワーク利用

このプラグインは、以下の任意かつユーザーが開始するリクエストを除き、完全にオフラインで動作します:

- **辞書 / 翻訳 / 発音**: `dict.youdao.com`、`translate.googleapis.com` / `translate.google.com`、`dict.iciba.com`、`api.mymemory.translated.net`
- **動画 & 字幕**（動画を開く/ダウンロードする、または購読を更新する際）: `www.youtube.com`、`i.ytimg.com` / `img.youtube.com`、`api.bilibili.com`、`www.bilibili.com`、`b23.tv`。モバイルでは YouTube の埋め込みが Obsidian 公式プロキシ `releases.obsidian.md` にフォールバックします
- **AI 機能**（プロバイダーを設定した場合のみ）: 選択したプロバイダーのエンドポイントを、**あなた自身の API キー**で呼び出します
- MDX 辞書はローカルファイルです — 何もダウンロードされません

## 🔒 プライバシー

- **テレメトリなし、アナリティクスなし、アカウント登録不要**
- デバイスから送信されるのは、あなたが開始した検索/翻訳と、**あなたが**設定した AI プロバイダーへのリクエストだけです

**ヴォールト外のファイルについて**: 辞書設定でデバイス上の別の場所にある MDX ファイルを指定することがあります。プラグインが読み取るのは、明示的に選択されたファイルだけです。

## 📋 変更履歴

### 4.2.0

- **10 言語のインターフェース** — 英語、簡体字/繁体字中国語、ドイツ語、フランス語、スペイン語、日本語、韓国語、ロシア語、タイ語。既定では Obsidian の言語設定に追従し、設定で上書きできます。切り替えると開いているビューは即座に再描画されます。
- **AI レポートの多言語化** — 英語プロンプトのバリアントを追加し、中国語以外の UI ではインターフェースの言語でレポートが出力されます。
- **より賢い翻訳チェーン** — 翻訳先の言語がインターフェースの言語に追従し、英語以外の学習言語では既定で Google 翻訳を使用します。
- **購入フローの多言語化** — 中国語以外のインターフェースでは、アップグレードダイアログから公式ウェブサイトが開きます。
- **内蔵ガイドの多言語化** — HTML ガイドが全 10 言語に対応しました。
- **ナビゲーションパネルの改善** — 統計表示とクイックアクションボタンが長い単語の言語に対応: 数字は 1 行に揃えられ、ラベルは折り返しや重なりがなく、ボタンのキャプションは 2 行までに収まります。
- **ナビゲーションパネルとフラッシュカード復習ビューでスクロールバーを完全に非表示**。
- マニフェストにバイリンガルのプラグイン説明（英語 + 中国語）を、中国語 README にバイリンガルの紹介文を追加。
