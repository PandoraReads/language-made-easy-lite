📦 下載安裝

你的倉庫/
└── .obsidian/

二、使用查詞功能

The best way to learn a new language is not through memorization, but through immersion. When you read, listen, and speak in context, your brain absorbs vocabulary and grammar naturally — just like how you learned your first language as a child.

試試在上面這段文字中 雙擊 你不認識的單詞，體驗查詞功能吧！

打開單詞助手

有多種方式：

方式一：點選左側邊欄的 📖 書本圖標

查詞操作

三、添加和管理閃卡

🎴 當你在閱讀和查詞過程中積累了不少生詞，現在想系統複習它們，你可以這樣做：

自動生成閃卡

查詞後點選 「加入生詞本」，插件會自動為你生成一張閃卡。每張卡片包含：

  • ✅ 單詞 + 音標
  • ✅ 釋義
  • ✅ 單詞上下文（查詞時所在的筆記句）
  • ✅ 來源筆記連結
  • ✅ 添加日期

手動添加閃卡

打開閃卡複習面板 → 點選底部的「添加閃卡」按鈕
→ 填寫單詞、音標（選填）、釋義、例句（選填）
→ 儲存

開始複習

打開閃卡複習面板：

方式一：點選左側邊欄的 🧠 大腦圖標
方式二：Ctrl/Cmd + P → 搜尋「開始閃卡複習」

複習流程

👀 看卡片正面 → 🤔 嘗試回憶單詞含義
→ 🖱️ 點選翻面查看釋義 → ⭐ 給自己的記憶程度評分

評分等級

🧠 關於 FSRS 演算法

閃卡複習由 FSRS 演算法（現代間隔重複演算法）驅動。它會根據你的評分，智能安排每張卡片的下次複習時間，讓你剛好在遺忘邊緣時複習。

評分含義效果
😵 忘記完全想不起來很快會再次出現
😐 困難勉強想起來縮短複習間隔
🙂 良好正常回憶起來按標準間隔安排
😎 簡單秒答出來大幅拉長複習間隔
🧹 自動清理

當一個單詞被多次評為 「簡單」 後，會自動退出複習隊列。你可以在 設置 → Language Made Easy 中自定義「自動清理」的觸發條件。

管理閃卡數據

Ctrl/Cmd + P → 搜尋「管理閃卡數據」

在管理器中你可以：

  • 📋 按語言和狀態篩選閃卡
  • 🗑️ 批量刪除不再需要的閃卡
  • 📤 導出閃卡數據
💡 兩個重要說明

1. 閃卡數據儲存在本地 IndexedDB 中。更新插件時只需替換 main.js、manifest.json、style.css 三個文件，已有的閃卡不會受影響，放心更新！

2. 閃卡支持 txt、markdown、csv、json 等多種格式的導入和導出，方便備份和遷移。

四、使用跟讀工坊

🎬 Language Made Easy 幫你更高效地從 YouTube / Bilibili 影片中學習，自然習得口語表達，磨練聽力。

打開跟讀工坊

方式一：點選左側邊欄的 ▶️ 播放圖標
方式二：Ctrl/Cmd + P → 搜尋「跟讀工坊」

載入影片

把影片鏈接貼進筆記，插件會自動識別並載入：

✅ YouTube 影片 → 貼上鏈接自動載入
✅ Bilibili 影片 → 貼上鏈接自動載入（自動下載 & 緩存）
✅ 本地音訊/影片 → 用 ![[video.mp4]] 或 ![[audio.mp3]] 嵌入

下載字幕

載入影片後，點選右側工具欄的 「下載字幕」 按鈕。插件會從 YouTube / Bilibili 抓取字幕並插入筆記。

字幕格式示例：

[00:12] Hello, how are you today?
[00:15] I'm fine, thank you. And you?
[01:23] What a beautiful day! Let's go for a walk.
📝 說明

跟讀工坊支持多種時間戳格式——無論 HH:MM:SS、MM:SS 還是 [00:12]，都能自動識別載入。

播放控制

跟讀工坊播放器底部有一排播放控制按鈕：

按鈕功能用途
⏮️ 重播跳到當前句子開頭從句子開頭重聽
🔁 循環單句循環播放適合精聽單句
▶️ / ⏸️ 播放/暫停控制播放空白鍵
🐢🐇 速度0.8x / 1.0x / 1.2x按自身水平調整

🎧 聽寫模式

想挑戰聽力？試試 聽寫模式！

跟讀工坊右側工具欄 → 點選「聽寫模式」按鈕
→ 播放一句，把聽到的內容打出来
→ 提交後自動與原文比對
→ 錯誤標紅，正確標綠

五、用 AI 為學習加速

想要更強大的學習體驗？下面的進階設置會解鎖本地詞典和 AI 解析等功能。

5.1 配置本地詞典

本地詞典（MDX 格式）能提供更豐富的釋義——包括例句、搭配、近義詞——而且離線可用。

設置 → Language Made Easy → 詞典設置
→ 填寫本地 MDX 詞典的文件路徑
→ 儲存

5.2 本地詞典效果

配置本地詞典後，查詞結果會豐富很多：

維度網路詞典本地 MDX 詞典
網路✅ 需要聯網❌ 離線可用
釋義詳細度基礎釋義詳解 + 例句 + 搭配
速度取決於網路⚡ 秒開
支持來源Google / MyMemory / Jisho自定義 MDX 文件

5.3 配置大模型 API Key

AI 解析功能需要大模型 API Key。目前支持的提供商：

設置 → Language Made Easy → AI 設置
→ 選擇模型提供商（OpenAI / Google Gemini / OpenRouter）
→ 輸入 API Key
→ 儲存
💡 推薦

- OpenAI：填入 API Key 即開即用。

- Google Gemini：有免費額度，適合作備用或深度學習。

5.4 使用 AI 解析

5.4.1 生成 AI 解析報告

在跟讀工坊載入字幕後：

點選右側工具欄的「AI 解析」按鈕
→ 等待解析完成（通常十到二十秒）
→ 報告顯示在右側面板
→ 點選「儲存到筆記」保留
→ 點選圖片按鈕可「儲存為長圖片」到本地

AI 解析報告通常包含：

  • 📝 詞彙——重點詞的用法和搭配
  • 🏗️ 語法——關鍵語法結構拆解
  • 🌍 文化背景——相關的文化語境
  • 💡 學習建議——針對性的學習提示

插件內置 3 種 AI 解析提示詞，對應不同學習需求：

提示詞適用場景產出
📝 概要快速掌握影片大意簡明摘要 + 要點
📖 雙語逐句精讀內容逐句雙語對照翻譯
🧪 隨堂測驗檢驗學習成果根據影片生成的測驗題
💡 你也可以自己編寫提示詞——見 5.4.2 添加自定義提示詞。

5.4.2 添加自定義提示詞

你可以自己編寫提示詞，讓 AI 按你的需求生成學習材料：

設置 → Language Made Easy → AI 提示詞管理
→ 添加自定義提示詞
→ 設置提示詞名稱和內容
→ 儲存

5.5 一鍵閃卡自動填充

添加閃卡時不想手動填音標和釋義？用 AI 自動填充！

添加閃卡面板 → 輸入單詞
→ 點選「AI 填充」按鈕
→ 自動填入音標、釋義、例句
→ 確認後儲存

5.6 更多字幕載入方式

除了在跟讀工坊直接下載字幕，還有幾種方式載入字幕：

5.6.1 使用跟讀工坊的「下載字幕」按鈕

最直接的方式。載入影片後，點選右側工具欄的 「下載字幕」 按鈕，插件會自動從 YouTube / Bilibili 抓取字幕。

⚠️ 字幕下載說明

1. 插件下載的是當前所選學習語言的字幕——下載前請確認語言無誤。若該語言無字幕，會返回影片的默認字幕。

2. Bilibili 影片往往沒有英語字幕。選影片前，先在 Bilibili 播放器的「字幕」列表確認有所需語言。

5.6.2 使用 Obsidian Web Clipper

安裝 Obsidian Web Clipper 瀏覽器擴展，看影片時可直接把 YouTube 字幕剪藏進 Obsidian 筆記：

安裝 Obsidian Web Clipper 瀏覽器擴展
→ 在 YouTube 影片頁點選擴展圖標
→ 選擇剪藏字幕內容
→ 自動保存為帶時間戳的筆記

5.6.3 使用 ytranscript 插件

ytranscript 是另一款 Obsidian 插件，可在 Obsidian 內下載 YouTube 字幕：

在 Obsidian 第三方插件中搜尋並安裝「ytranscript」
→ 從命令面板用 ytranscript 抓取 YouTube 字幕
→ 字幕帶時間戳插入筆記
→ 打開跟讀工坊開始使用

5.6.4 為本地影片載入 SRT 文件

如果你有本地影片文件和對應的 SRT 字幕文件：

方式一：把 SRT 文件內容複製進筆記
         → 確認 SRT 時間戳格式正確
         → 用 ![[video.mp4]] 把影片嵌入筆記
         → 打開跟讀工坊解析影片和字幕

方式二：把 SRT 文件放在倉庫中影片文件旁
         → 用 ![[video.mp4]] 把影片嵌入筆記
         → 插件自動匹配同名 SRT 文件

七、常見問題

❓ 查詞沒反應？

請檢查以下幾點：

1. 確認詞典配置無誤（網路詞典需要聯網）。

2. 若使用 MDX 詞典，請確認設置中 mdx、mdd、css 文件路徑填寫正確。

3. 確認當前學習語言設置正確。

❓ 剛添加的閃卡看不到？

新添加的閃卡會排在複習隊列的最末尾。

❓ Bilibili 影片只下載到中文字幕？

請確認影片本身是否上傳了其他語言的字幕文件。畫面上燒錄的雙語字幕，不代表作者提供了對應的字幕文件。

❓ 打開 YouTube 影片時提示「登入」？

切換網路通常可以解決。這一般與當前網路環境有關——換個網路節點再試。

❓ AI 解析報錯？

請檢查：

1. API Key 是否配置正確？

2. 網路連接是否正常？

3. API 餘額是否充足？
