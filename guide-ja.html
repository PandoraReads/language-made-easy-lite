Language Made Easy は、単語検索・フラッシュカード・動画シャドーイング・AI 分析をノート作業にそのまま組み込む Obsidian プラグインです。記事を読み、動画を見、ノートを取るうちに言語が自然に身につきます。

1. プラグインのインストール

📦 ダウンロードとインストール

  1. プラグインのファイル（main.js、manifest.json、style.css）を Obsidian の Vault のプラグインフォルダにコピーします:
your-vault/
└── .obsidian/
    └── plugins/
        └── language-made-easy/
            ├── main.js
            ├── manifest.json
            └── style.css
💡 プラグインフォルダの見つけ方は？

Obsidian で 設定 → コミュニティプラグイン → 📁 アイコンをクリックすると、プラグインフォルダへ直接ジャンプできます。

  1. Obsidian に戻り、設定 → コミュニティプラグインで Language Made Easy を見つけてオンにします。

🆓 3 日間無料体験 → フルエディション

3 日間の無料体験は初回起動から始まります——すべての言語が学習可能（検索／カード／シャドーイング／AI 分析）で、機能はベーシック構成のまま。残り時間はステータスバーに表示されます。

体験終了後はフルエディション（買い切り、生涯アップデート）をご入手いただくと引き続きご利用いただけます。すべての上級モジュールが解放されます：

  • 他 7 言語: 英語 / ドイツ語 / フランス語 / スペイン語 / 韓国語 / ロシア語 / 日本語
  • カード無制限、ローカル辞書 5 冊、モバイル オフライン辞書
  • カードの端末間同期、データの入出力
  • AI 一括カード生成、AI レポート書き出し
  • 追加 UI テーマ 9 種、リスニング / タイピング復習モード
  • 動画ブックマーク、動画講解カード、登録チャンネルページからワンクリック・一括ダウンロード

🌐 https://languagemadeeasy.com でフルエディションを入手できます。

2. 単語検索の使い方

📖 これは英語のサンプル文章です:

The best way to learn a new language is not through memorization, but through immersion. When you read, listen, and speak in context, your brain absorbs vocabulary and grammar naturally — just like how you learned your first language as a child.

上の文章の中の知らない単語をダブルクリックして、検索を試してみましょう！

単語アシスタントを開く

いくつか方法があります:

方法 1: 左サイドバーの 📖 ブックアイコンをクリック
方法 2: Ctrl/Cmd + P → 「単語アシスタント」で自動検索

検索操作

ノート内で単語をダブルクリック、または Ctrl/Cmd + Shift を押しながらテキストを選択すると、結果パネルが右側に自動表示されます。

3. カードの追加と管理

🎴 読書と検索で新しい単語をたくさん溜めたら、こんなふうに体系的に復習できます:

自動生成カード

検索後に 「単語帳に追加」 をクリックすると、プラグインが自動でカードを作成します。各カードには:

  • ✅ 単語 + 発音記号
  • ✅ 意味
  • ✅ 単語の文脈（検索したノート内の文章）
  • ✅ 元ノートへのリンク
  • ✅ 追加日

カードを手動で追加

カード復習パネルを開く → 下部の「カードを追加」をクリック
→ 単語、発音記号（任意）、意味、例文（任意）を入力
→ 保存

復習を始める

カード復習パネルを開きます:

方法 1: 左サイドバーの 🧠 アイコンをクリック
方法 2: Ctrl/Cmd + P → 「フラッシュカード復習を開始」を検索

復習の流れ

👀 カードの表を見る → 🤔 意味を思い出す
→ 🖱️ クリックしてめくり意味を確認 → ⭐ 記憶度を評価

評価の段階

🧠 FSRS アルゴリズムについて

復習は FSRS アルゴリズム（最新の間隔反復アルゴリズム）で駆動されます。あなたの評価に基づいて各カードの次回復習時期を賢くスケジュールし、忘れかけのタイミングで復習させます。

評価意味効果
😵 もう一度全然思い出せないすぐ再出題
😐 難しいかろうじて思い出した間隔を短縮
🙂 良い普通に思い出した標準間隔
😎 簡単即答できた間隔を大きく延長
🧹 自動クリーンアップ

単語が複数回 「簡単」 と評価されると、自動で復習ローテーションから外れます。トリガーは 設定 → Language Made Easy でカスタマイズできます。

カードデータの管理

Ctrl/Cmd + P → 「カードデータを管理」を検索

マネージャーでは:

  • 📋 言語と状態でカードを絞り込み
  • 🗑️ 不要になったカードを一括削除
  • 📤 カードデータをエクスポート
💡 2 つの重要な説明

1. カードデータはローカルの IndexedDB に保存されます。プラグイン更新時は main.js、manifest.json、style.css の 3 ファイルを置き換えるだけで、既存のカードには影響しません。安心して更新してください！

2. カードは txt、markdown、csv、json など複数形式のインポート・エクスポートに対応し、バックアップや移行が容易です。

4. シャドーイング工房の使い方

🎬 Language Made Easy は YouTube / Bilibili 動画からの学習を効率化し、自然な話し言葉の習得とリスニング強化を支援します。

工房を開く

方法 1: 左サイドバーの ▶️ アイコンをクリック
方法 2: Ctrl/Cmd + P → 「シャドーイング工房」を検索

動画を読み込む

ノートに動画リンクを貼ると、プラグインが自動で認識して読み込みます:

✅ YouTube 動画 → リンクを貼るだけで自動読み込み
✅ Bilibili 動画 → リンクを貼るだけで自動読み込み（自動ダウンロード & キャッシュ）
✅ ローカル音声/動画 → ![[video.mp4]] や ![[audio.mp3]] で埋め込み

字幕をダウンロード

読み込み後、右ツールバーの 「字幕ダウンロード」 をクリック。YouTube / Bilibili から字幕を取得してノートに挿入します。

字幕フォーマットの例:

[00:12] Hello, how are you today?
[00:15] I'm fine, thank you. And you?
[01:23] What a beautiful day! Let's go for a walk.
📝 補足

工房は複数のタイムスタンプ形式に対応 — HH:MM:SS、MM:SS、[00:12] のどれでも自動認識して読み込みます。

再生コントロール

工房のプレーヤー下部には操作ボタンが並んでいます:

ボタン機能用途
⏮️ リプレイ現在の文の先頭へ文の頭から聴き直す
🔁 ループ一文ループ一文を徹底トレーニング
▶️ / ⏸️ 再生/一時停止再生を制御スペースキー
🐢🐇 速度0.8x / 1.0x / 1.2xレベルに合わせて調整

🎧 ディクテーションモード

リスニングに挑戦したい？ ディクテーションモードを試してみましょう！

工房の右ツールバー → 「ディクテーションモード」をクリック
→ 一文再生され、聞こえた内容をタイピング
→ 送信すると元文と自動比較
→ 誤りは赤、正しい部分は緑で表示

5. AI で学習をレベルアップ

もっと強力な学習体験を求めるなら？ 以下の高度な設定でローカル辞書や AI 分析などが解放されます。

5.1 ローカル辞書を設定

ローカル辞書（MDX 形式）は、例文・コロケーション・類義語を含む豊富な語義をオフラインでも提供します。

設定 → Language Made Easy → 辞書設定
→ ローカル MDX 辞書のファイルパスを設定
→ 保存

5.2 ローカル辞書の効果

ローカル辞書を設定すると、検索結果が格段に充実します:

観点オンライン辞書ローカル MDX 辞書
ネットワーク✅ 必要❌ オフラインで動作
語義の詳細さ基本的な語義詳細 + 例文 + コロケーション
速度ネットワーク次第⚡ 一瞬
対応ソースGoogle / MyMemory / Jisho任意の MDX ファイル

5.3 LLM API キーを設定

AI 分析には大規模言語モデルの API キーが必要です。対応プロバイダー:

設定 → Language Made Easy → AI 設定
→ モデルプロバイダーを選択（OpenAI / Google Gemini / OpenRouter）
→ API キーを入力
→ 保存
💡 おすすめ

- OpenAI: API キーを入れるだけで即使えます。

- Google Gemini: 無料枠あり。バックアップや深い学習に最適。

5.4 AI 分析の使い方

5.4.1 AI 分析レポートを生成

工房で字幕を読み込んだ後:

右ツールバーの「AI 分析」をクリック
→ 解析完了を待つ（通常 10〜20 秒）
→ レポートが右パネルに表示
→ 「ノートに保存」で保持
→ 画像ボタンで「縦長画像として保存」も可能

AI 分析レポートには通常:

  • 📝 語彙 — 重要単語の用法とコロケーション
  • 🏗️ 文法 — 重要構造の分解
  • 🌍 文化背景 — 関連する文化的文脈
  • 💡 学習ヒント — 的確な学習アドバイス

プラグインには学習目的別の 3 つの内蔵プロンプトがあります:

プロンプト向いている場面出力
📝 要約動画の要点をすばやく把握簡潔な要約 + ポイント
📖 バイリンガル一文ずつ精読文ごとの対訳
🧪 ミニクイズ学習成果を確認動画からのクイズ問題
💡 自分でプロンプトを書くこともできます — 5.4.2 カスタムプロンプトを追加 を参照。

5.4.2 カスタムプロンプトを追加

自分でプロンプトを書いて、ニーズに合った教材を AI に作らせられます:

設定 → Language Made Easy → AI プロンプト管理
→ カスタムプロンプトを追加
→ 名前と内容を設定
→ 保存

5.5 ワンクリックでカード自動入力

カード追加時に発音記号や意味を手入力したくない？ AI 自動入力を使いましょう！

カード追加パネル → 単語を入力
→ 「AI 入力」ボタンをクリック
→ 発音記号・意味・例文が自動で入る
→ 確認して保存

5.6 字幕の他の読み込み方法

工房での直接ダウンロード以外にも、いくつか方法があります:

5.6.1 工房の「字幕ダウンロード」ボタンを使う

最も直接的な方法。動画読み込み後、右ツールバーの 「字幕ダウンロード」 をクリックすると、YouTube / Bilibili から自動取得します。

⚠️ 字幕ダウンロードの注意

1. プラグインは現在選択中の学習言語の字幕をダウンロードします — ダウンロード前に言語を確認してください。その言語の字幕がない場合は動画のデフォルト字幕が返されます。

2. Bilibili 動画には英語字幕がないことが多いです。動画を選ぶ前に Bilibili プレーヤーの「字幕」リストで必要な言語があるか確認しましょう。

5.6.2 Obsidian Web Clipper を使う

Obsidian Web Clipper ブラウザ拡張を使うと、視聴中に YouTube 字幕をそのまま Obsidian ノートにクリップできます:

Obsidian Web Clipper 拡張をインストール
→ YouTube 動画ページで拡張アイコンをクリック
→ 字幕コンテンツのクリップを選択
→ タイムスタンプ付きノートとして自動保存

5.6.3 ytranscript プラグインを使う

ytranscript は、Obsidian 内で YouTube 字幕をダウンロードできるもう一つのプラグインです:

コミュニティプラグインから「ytranscript」を検索してインストール
→ コマンドパレットから ytranscript で YouTube 字幕を取得
→ 字幕がタイムスタンプ付きでノートに挿入
→ シャドーイング工房を開いて使う

5.6.4 ローカル動画に SRT ファイルを読み込む

ローカル動画ファイルと対応する SRT 字幕ファイルがある場合:

方法 1: SRT ファイルの内容をノートにコピー
         → SRT のタイムスタンプ形式が正しいか確認
         → ![[video.mp4]] で動画をノートに埋め込む
         → 工房を開いて動画と字幕を解析

方法 2: Vault 内で SRT ファイルを動画の隣に置く
         → ![[video.mp4]] で動画を埋め込む
         → プラグインが同名の SRT を自動照合

7. FAQ

❓ 検索が反応しない？

以下を確認してください:

1. 辞書が正しく設定されているか（オンライン辞書にはネット接続が必要）。

2. MDX 辞書を使う場合、設定の mdx・mdd・css のパスが正しいか。

3. 現在の学習言語が正しく設定されているか。

❓ 追加したばかりのカードが見当たらない？

新しく追加したカードは復習キューの一番最後に並びます。

❓ Bilibili 動画で中国語字幕しかダウンロードされない？

その動画に他言語の字幕が実際にアップロードされているか確認してください。画面に焼き付けられた二言語字幕は、投稿者がそれらの字幕ファイルを提供しているとは限りません。

❓ YouTube 動画を開くと「ログイン」を求められる？

ネットワークを切り替えると大抵解決します。現在のネット環境起因であることが多く、別のノードを試してみてください。

❓ AI 分析でエラーが出る？

確認してください:

1. API キーは正しく設定されていますか？

2. ネット接続は正常ですか？

3. API 残高は十分ですか？
