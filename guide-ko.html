📦 다운로드 및 설치

  1. 플러그인 파일들(main.js, manifest.json, style.css)을 Obsidian Vault의 플러그인 폴더에 복사하세요:
your-vault/
└── .obsidian/

        └── language-made-easy/

  1. Obsidian으로 돌아와 설정 → 커뮤니티 플러그인에서 Language Made Easy를 찾아 켜세요.

2. 단어 검색 사용하기

The best way to learn a new language is not through memorization, but through immersion. When you read, listen, and speak in context, your brain absorbs vocabulary and grammar naturally — just like how you learned your first language as a child.

위 문단에서 모르는 단어를 더블클릭해서 검색 기능을 체험해 보세요!

단어 어시스턴트 열기

여러 가지 방법이 있어요:

방법 1: 왼쪽 사이드바의 📖 책 아이콘 클릭
방법 2: Ctrl/Cmd + P → "단어 어시스턴트"로 자동 검색

검색 동작

노트에서 단어를 더블클릭하거나 Ctrl/Cmd + Shift를 누른 채 텍스트를 선택하면, 결과 패널이 오른쪽에 자동으로 떠요.

검색 결과 패널

단어를 검색하면 이런 게 보여요:

결과 패널 안에서도 더블클릭으로 검색할 수 있어요 — 사전 자체도 훌륭한 학습 자료예요!

3. 카드 추가하고 관리하기

🎴 읽고 검색하면서 새 단어를 많이 모았다면, 이렇게 체계적으로 복습할 수 있어요:

자동 생성 카드

검색 후 "단어장에 추가"를 누르면 플러그인이 자동으로 카드를 만들어 줘요. 각 카드에는:

  • ✅ 단어 + 발음 기호
  • ✅ 뜻
  • ✅ 단어의 문맥(검색한 노트의 문장)
  • ✅ 원본 노트 링크
  • ✅ 추가한 날짜

카드 직접 추가하기

카드 복습 패널 열기 → 하단의 "카드 추가" 버튼 클릭
→ 단어, 발음 기호(선택), 뜻, 예문(선택) 입력
→ 저장

복습 시작하기

카드 복습 패널을 여세요:

방법 1: 왼쪽 사이드바의 🧠 아이콘 클릭
방법 2: Ctrl/Cmd + P → "플래시카드 복습 시작" 검색

복습 흐름

👀 카드 앞면 보기 → 🤔 뜻을 떠올려 보기
→ 🖱️ 클릭해 뒤집고 뜻 확인 → ⭐ 기억 정도 평가하기

평가 등급

🧠 FSRS 알고리즘 소개

복습은 FSRS 알고리즘(최신 간격 반복 알고리즘)으로 돌아가요. 평가에 따라 각 카드의 다음 복습 시기를 똑똑하게 배정해, 딱 잊을 때쯤 다시 보게 해줍니다.

평가의미효과
😵 다시전혀 기억 안 남곧 다시 출제
😐 어려움겨우 기억함간격 단축
🙂 좋음보통으로 기억함표준 간격
😎 쉬움바로 답함간격 크게 연장
🧹 자동 정리

단어가 여러 번 "쉬움"으로 평가되면 자동으로 복습 순환에서 빠져요. "자동 정리" 조건은 설정 → Language Made Easy에서 바꿀 수 있어요.

카드 데이터 관리

Ctrl/Cmd + P → "카드 데이터 관리" 검색

관리자에서는:

  • 📋 언어와 상태로 카드 필터링
  • 🗑️ 필요 없는 카드 일괄 삭제
  • 📤 카드 데이터 내보내기
💡 중요한 두 가지

1. 카드 데이터는 로컬 IndexedDB에 저장돼요. 플러그인 업데이트 시 main.js, manifest.json, style.css 세 파일만 바꾸면 되고 기존 카드는 영향을 받지 않아요. 안심하고 업데이트하세요!

2. 카드는 txt, markdown, csv, json 등 여러 형식의 가져오기/내보내기를 지원해 백업과 이동이 쉬워요.

4. 셰도잉 워크숍 사용하기

🎬 Language Made Easy는 YouTube / Bilibili 영상으로 더 효율적으로 공부하도록 도와줘요. 자연스러운 구어체를 익히고 듣기를 단련하세요.

워크숍 열기

방법 1: 왼쪽 사이드바의 ▶️ 아이콘 클릭
방법 2: Ctrl/Cmd + P → "셰도잉 워크숍" 검색

영상 불러오기

노트에 영상 링크를 붙이면 플러그인이 자동으로 인식하고 불러와요:

✅ YouTube 영상 → 링크만 붙이면 자동 로드
✅ Bilibili 영상 → 링크만 붙이면 자동 로드(자동 다운로드 & 캐시)
✅ 로컬 오디오/영상 → ![[video.mp4]] 또는 ![[audio.mp3]]로 삽입

자막 다운로드

불러온 뒤 오른쪽 도구 모음의 "자막 다운로드"를 클릭하세요. YouTube / Bilibili에서 자막을 가져와 노트에 넣어줘요.

자막 형식 예시:

[00:12] Hello, how are you today?
[00:15] I'm fine, thank you. And you?
[01:23] What a beautiful day! Let's go for a walk.
📝 참고

워크숍은 다양한 타임스탬프 형식을 지원해요 — HH:MM:SS, MM:SS, [00:12] 모두 자동 인식해 불러옵니다.

재생 컨트롤

워크숍 플레이어 하단에는 재생 컨트롤이 한 줄 있어요:

버튼기능용도
⏮️ 리플레이현재 문장 처음으로문장 처음부터 다시 듣기
🔁 루프한 문장 반복한 문장 집중 훈련에 최적
▶️ / ⏸️ 재생/일시정지재생 제어스페이스바
🐢🐇 속도0.8x / 1.0x / 1.2x내 수준에 맞게 조절

🎧 받아쓰기 모드

듣기에 도전하고 싶나요? 받아쓰기 모드를 사용해 보세요!

워크숍 오른쪽 도구 모음 → "받아쓰기 모드" 클릭
→ 한 문장이 재생되면 들리는 대로 입력
→ 제출하면 원문과 자동 비교
→ 틀린 곳은 빨강, 맞은 곳은 초록

5. AI로 학습 업그레이드

더 강력한 경험을 원하세요? 아래 고급 설정이 로컬 사전과 AI 분석 같은 기능을 열어줘요.

5.1 로컬 사전 설정

로컬 사전(MDX 형식)은 예문, 연어, 유의어까지 담은 풍부한 뜻풀이를 오프라인에서도 제공해요.

설정 → Language Made Easy → 사전 설정
→ 로컬 MDX 사전 파일 경로 지정
→ 저장

5.2 로컬 사전의 효과

로컬 사전을 설정하면 검색 결과가 훨씬 풍부해져요:

항목온라인 사전로컬 MDX 사전
네트워크✅ 필요❌ 오프라인 동작
뜻풀이 상세도기본 뜻풀이상세 + 예문 + 연어
속도네트워크에 따라⚡ 즉시
지원 소스Google / MyMemory / Jisho직접 MDX 파일

5.3 LLM API 키 설정

AI 분석에는 대규모 언어 모델의 API 키가 필요해요. 지원되는 제공자:

설정 → Language Made Easy → AI 설정
→ 모델 제공자 선택 (OpenAI / Google Gemini / OpenRouter)
→ API 키 입력
→ 저장
💡 추천

- OpenAI: API 키만 넣으면 바로 사용 가능.

- Google Gemini: 무료 사용권이 있어요. 백업이나 깊이 있는 학습에 좋아요.

5.4 AI 분석 사용하기

5.4.1 AI 분석 리포트 생성

워크숍에서 자막을 불러온 뒤:

오른쪽 도구 모음의 "AI 분석" 클릭
→ 분석이 끝나길 기다려요 (보통 10~20초)
→ 리포트가 오른쪽 패널에 표시
→ "노트에 저장"으로 보관
→ 이미지 버튼으로 "긴 이미지로 저장"도 가능

AI 분석 리포트에는 보통 이런 내용이 있어요:

  • 📝 어휘 — 핵심 단어의 용법과 연어
  • 🏗️ 문법 — 핵심 구조 해설
  • 🌍 문화 배경 — 관련 문화적 맥락
  • 💡 학습 팁 — 맞춤형 학습 제안

플러그인에는 목적별 3가지 내장 프롬프트가 있어요:

프롬프트적합한 상황산출물
📝 요약영상 내용 빠르게 파악간결한 요약 + 핵심 포인트
📖 이중 언어한 줄씩 정독문장별 이중 언어 대역
🧪 미니 퀴즈학습 점검영상 기반 퀴즈 문항
💡 직접 프롬프트를 쓸 수도 있어요 — 5.4.2 사용자 지정 프롬프트 추가 참고.

5.4.2 사용자 지정 프롬프트 추가

직접 프롬프트를 써서 필요에 맞는 학습 자료를 AI에게 받아 보세요:

설정 → Language Made Easy → AI 프롬프트 관리
→ 사용자 지정 프롬프트 추가
→ 이름과 내용 설정
→ 저장

5.5 원클릭 카드 자동 채우기

카드 추가할 때 발음 기호와 뜻을 직접 입력하기 귀찮다면? AI 자동 채우기를 쓰세요!

카드 추가 패널 → 단어 입력
→ "AI 채우기" 버튼 클릭
→ 발음 기호, 뜻, 예문이 자동으로 채워져요
→ 확인 후 저장

5.6 자막을 불러오는 더 많은 방법

워크숍에서 바로 받는 것 말고도 여러 방법이 있어요:

5.6.1 워크숍의 "자막 다운로드" 버튼

가장 직접적인 방법이에요. 영상을 불러온 뒤 오른쪽 도구 모음의 "자막 다운로드"를 클릭하면 YouTube / Bilibili에서 자동으로 가져와요.

⚠️ 자막 다운로드 유의사항

1. 플러그인은 현재 선택한 학습 언어의 자막을 내려받아요 — 다운로드 전에 언어를 확인하세요. 해당 언어 자막이 없으면 영상의 기본 자막이 반환돼요.

2. Bilibili 영상에는 영어 자막이 없는 경우가 많아요. 영상을 고르기 전에 Bilibili 플레이어의 "字幕"(자막) 목록에서 필요한 언어가 있는지 확인하세요.

5.6.2 Obsidian Web Clipper 사용

Obsidian Web Clipper 브라우저 확장을 쓰면 시청 중에 YouTube 자막을 바로 Obsidian 노트로 클립할 수 있어요:

Obsidian Web Clipper 확장 설치
→ YouTube 영상 페이지에서 확장 아이콘 클릭
→ 자막 내용 클립 선택
→ 타임스탬프가 붙은 노트로 자동 저장

5.6.3 ytranscript 플러그인 사용

ytranscript는 Obsidian 안에서 YouTube 자막을 내려받는 또 다른 플러그인이에요:

커뮤니티 플러그인에서 "ytranscript" 검색 후 설치
→ 명령 팔레트에서 ytranscript로 YouTube 자막 받기
→ 자막이 타임스탬프와 함께 노트에 삽입
→ 워크숍을 열어 사용 시작

5.6.4 로컬 영상에 SRT 파일 불러오기

로컬 영상 파일과 짝이 맞는 SRT 자막 파일이 있다면:

방법 1: SRT 파일 내용을 노트에 복사
         → SRT 타임스탬프 형식이 맞는지 확인
         → ![[video.mp4]]로 영상을 노트에 삽입
         → 워크숍을 열어 영상과 자막 해석

방법 2: Vault에서 SRT 파일을 영상 옆에 두기
         → ![[video.mp4]]로 영상 삽입
         → 플러그인이 같은 이름의 SRT를 자동으로 연결

6.2 퀵 커맨드: 원클릭 언어 전환

여러 언어를 공부 중이라면? 빠르게 바꿔 보세요:

Ctrl/Cmd + P → "영어 / 독일어 / 프랑스어 / … 으로 전환" 검색
→ 현재 학습 언어가 즉시 바뀌어요

6.3 퀵 커맨드: AI 분석 리포트

Ctrl/Cmd + P → "AI 분석" 검색
→ Vault의 아무 노트나 골라 AI 분석 실행

6.4 단어장 저장 경로 설정

단어를 추가할 때마다 플러그인이 Vault에 Markdown 단어장 파일을 만들어요. 저장 위치를 바꿀 수 있어요:

설정 → Language Made Easy → 단어장 설정
→ 저장 경로와 파일명 지정
→ 저장

6.5 AI 분석 리포트 저장 경로 설정

AI 리포트도 원하는 위치에 저장할 수 있어요:

설정 → Language Made Easy → AI 분석 설정
→ 리포트 저장 경로 지정
→ 저장

7. FAQ

❓ 검색이 반응하지 않아요?

다음을 확인해 주세요:

1. 사전이 제대로 설정되어 있는지(온라인 사전은 네트워크가 필요해요).

2. MDX 사전을 쓴다면 설정의 mdx, mdd, css 경로가 정확한지.

3. 현재 학습 언어가 올바르게 설정되어 있는지.

❓ 방금 추가한 카드가 안 보여요?

새 카드는 복습 대기열 맨 끝에 붙어요.

❓ Bilibili 영상이 중국어 자막만 받아져요?

그 영상에 실제로 다른 언어 자막 파일이 올라와 있는지 확인해 보세요. 화면에 새겨진 이중 언어 자막이 올리는 사람이 그 파일들을 제공한다는 뜻은 아니에요.

❓ YouTube 영상을 열면 "로그인"을 요구해요?

네트워크 전환으로 대부분 해결돼요. 보통 현재 네트워크 환경과 관련 있어요 — 다른 노드로 바꿔 다시 시도해 보세요.

❓ AI 분석에서 오류가 나요?

확인해 주세요:

1. API 키가 올바르게 설정되었나요?

2. 네트워크 연결이 정상인가요?

3. API 잔액이 충분한가요?
