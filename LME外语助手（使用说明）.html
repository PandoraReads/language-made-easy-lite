Language Made Easy · 使用说明

Obsidian 沉浸式外语学习插件 · 查词 / 闪卡 / 跟读 / AI

安装查词闪卡跟读AI更多FAQ插件

Language Made Easy 是一款 Obsidian 外语学习插件，把查词、闪卡、视频跟读、AI 解析整合到你的笔记工作流中，让你在读文章、看视频、记笔记的同时自然习得语言。

一、安装插件

📦 下载安装

  1. 将收到的插件文件（main.js、manifest.json、style.css）复制到 Obsidian 仓库的插件目录：
你的仓库/
└── .obsidian/
    └── plugins/
        └── language-made-easy/
            ├── main.js
            ├── manifest.json
            └── style.css
💡 如何找到插件目录？

在 Obsidian 中打开 设置 → 第三方插件 → 点击📁图标，即可直接跳转到插件目录。

  1. 回到 Obsidian，进入 设置 → 第三方插件，找到 Language Made Easy，打开开关启用。

三、添加和管理闪卡

🎴 当你在阅读和查词过程中积累了不少生词，现在想系统复习它们，你可以这样做：

自动生成闪卡

当你查词后点击 「加入生词本」，插件会自动为你生成一张闪卡。每张闪卡包含：

  • ✅ 单词 + 音标
  • ✅ 中文释义
  • ✅ 单词上下文（来自你查词时的笔记位置）
  • ✅ 来源笔记链接
  • ✅ 添加日期

手动添加闪卡

打开闪卡复习界面 → 点击底部「添加闪卡」按钮
→ 填写单词、音标（可选）、释义、例句（可选）
→ 保存

开始复习

打开闪卡复习面板：

方式一：点击左侧边栏的 🧠 大脑图标
方式二：Ctrl/Cmd + P → 搜索「开始闪卡复习」

复习流程

👀 看到单词正面 → 🤔 尝试回忆含义
→ 🖱️ 点击翻转查看释义 → ⭐ 根据记忆情况评分

评分标准

🧠 关于 FSRS 算法

闪卡复习基于 FSRS 算法（现代间隔重复算法），会根据你的评分智能安排每张卡片的下次复习时间，让你在遗忘临界点精准复习。

评分含义效果
😵 忘记了完全不记得短期内再次出现
😐 有困难勉强想起来适当缩短间隔
🙂 还可以正常回忆起来标准间隔安排
😎 已掌握非常确定大幅延长间隔
🧹 自动清理机制

当一个单词多次被标注为「已掌握」后，会自动从闪卡复习系统中移除。你可以在 设置 → Language Made Easy 中自定义管理「自动清理」功能的触发条件。

管理闪卡数据

Ctrl/Cmd + P → 搜索「管理闪卡数据」

在管理器中你可以：

  • 📋 按语言、状态筛选闪卡
  • 🗑️ 批量删除不需要的闪卡
  • 📤 导出闪卡数据
💡 两个重要提醒

1. 闪卡数据保存在本地 IndexedDB 中，更新插件时只需替换 main.js、manifest.json、style.css 三个文件，不会影响已有的闪卡数据，放心更新！

2. 闪卡支持导出和导入多种格式：txt、markdown、csv、json 等，方便备份和迁移。

四、使用跟读工坊

🎬 Language Made Easy能帮助你更高效学习YouTube / B站视频，掌握更生动的口语和过硬的听力。

打开跟读工坊

方式一：点击左侧边栏的 ▶️ 播放图标
方式二：Ctrl/Cmd + P → 搜索「跟读工坊」

加载视频

在笔记中粘贴视频链接，插件会自动识别并加载：

✅ YouTube 视频 → 粘贴链接自动加载
✅ B站视频     → 粘贴链接自动加载（自动下载缓存）
✅ 本地音视频   → 使用 ![[video.mp4]] 或 ![[audio.mp3]] 嵌入

下载字幕

加载视频后，点击右侧工具栏的 「下载字幕」 按钮，插件会自动从 YouTube / B站下载字幕并插入到笔记中。

字幕格式示例：

[00:12] Hello, how are you today?
[00:15] I'm fine, thank you. And you?
[01:23] What a beautiful day! Let's go for a walk.
📝 温馨提醒

跟读工坊支持多种时间戳格式的字幕文本，无论是 HH:MM:SS、MM:SS 还是 [00:12] 格式，都能自动识别并加载。

播放控制栏

跟读工坊播放器底部有一排播放控制按钮：

按钮功能快捷键提示
⏮️ 重播回到当前句开头回到句首重听
🔁 复读单句循环模式适合反复练习同一句
▶️ / ⏸️ 播放/暂停控制播放空格键
🐢🐇 语速调节0.8x / 1.0x / 1.2x根据水平调整

🎧 听写模式

想挑战一下自己的听力？试试 听写模式！

跟读工坊右侧工具栏 → 点击「听写模式」按钮
→ 播放句子，你来听写输入
→ 提交后自动对比你的输入与原文
→ 红色标记错误部分，绿色标记正确部分

五、用AI升级学习体验

想要更强大的学习体验？以下是进阶配置，解锁本地词典、AI 解析等高级功能。

5.1 配置本地词典

本地词典（MDX 格式）可以在离线状态下提供更详细的释义，包括例句、词组搭配、同义词等。

设置 → Language Made Easy → 词典设置
→ 配置本地 MDX 词典文件路径
→ 保存

5.2 演示本地词典效果

配置本地词典后，查词结果会变得更加丰富：

对比项在线词典本地 MDX 词典
网络要求✅ 需要联网❌ 离线可用
释义详细程度基础释义详细释义 + 例句 + 搭配
响应速度依赖网络⚡ 极速
支持词典有道/Google/MyMemory自定义 MDX 文件

5.3 配置大模型密钥

AI 解析功能需要配置大模型的 API 密钥。目前支持：

设置 → Language Made Easy → AI 设置
→ 选择模型提供商（Deepseek / Google Gemini）
→ 输入 API 密钥
→ 保存
💡 推荐

- Deepseek：性价比高，适合日常使用

- Google Gemini：免费且高质量的大模型，适合备用或者深度学习

5.4 使用 AI 解析

5.4.1 生成 AI 解析报告

在跟读工坊中加载字幕后：

点击右侧工具栏「AI 解析」按钮
→ 等待分析完成（通常需要十几秒）
→ 报告在右侧面板中显示
→ 可将报告「保存到笔记」中
→ 点击图片按钮「保存长图」到本地

AI 解析报告通常包含：

  • 📝 词汇讲解 — 重点词汇的用法和搭配
  • 🏗️ 语法分析 — 关键语法结构讲解
  • 🌍 文化背景 — 相关文化知识补充
  • 💡 学习建议 — 针对性的学习提示

插件预置了 3 套 AI 解析提示词，满足不同学习需求：

提示词适用场景输出内容
📝 视频概要快速了解视频大意简洁摘要 + 关键要点
📖 双语对照精读理解每一句话逐句中英对照翻译
🧪 小测验检验学习效果基于视频内容生成的测验题
💡 你也可以编写自己的提示词，详见 5.4.2 添加自定义提示词。

5.4.2 添加自定义提示词

你可以编写自己的提示词，让 AI 按照你的需求生成学习材料：

设置 → Language Made Easy → AI 提示词管理
→ 添加自定义提示词
→ 设置提示词名称和内容
→ 保存

5.5 闪卡一键补齐功能

添加闪卡时不想手动填写音标和释义？使用 AI 一键补齐！

添加闪卡界面 → 输入单词
→ 点击「AI 补齐」按钮
→ 自动填充音标、释义、例句
→ 确认保存

5.6 更多字幕加载方法

除了在跟读工坊中直接下载字幕，还有以下方式加载字幕：

5.6.1 使用跟读工坊的「下载字幕」按钮

最直接的方式。加载视频后，点击右侧工具栏的 「下载字幕」 按钮，插件会自动从 YouTube / B站获取字幕。

⚠️ 字幕下载须知

1. 插件会根据当前语种设置下载对应语言的字幕，下载前请确认语种是否正确；如果未搜索到对应语种的字幕，则会返回视频的默认字幕。

2. B站视频经常不包含英文字幕，选择视频前可在 B站播放器的「字幕」列表中确认是否有你需要的语言字幕。

5.6.2 使用 Obsidian Web Clipper

通过 Obsidian Web Clipper浏览器扩展，在观看 YouTube 视频时一键将字幕剪藏到 Obsidian 笔记中。

安装 Obsidian Web Clipper 浏览器扩展
→ 在 YouTube 视频页面点击扩展图标
→ 选择剪藏字幕内容
→ 自动保存为带时间戳格式的笔记

5.6.3 使用 ytranscript 插件

ytranscript是另一款 Obsidian 插件，可以帮你在Obsidian中下载油管字幕：

在Obsidian第三方市场中搜索并安装 ytranscript 插件
→ 在快捷命令中使用ytranscript获取youtube字幕
→ 字幕自动以带时间戳格式插入笔记
→ 打开跟读工坊即可使用

5.6.4 本地视频加载 SRT 文件

如果你有本地视频文件和对应的 SRT 字幕文件：

方式一：将 SRT 文件内容复制到笔记中
       → 确保 SRT 时间戳格式正确
       → 在笔记中嵌入视频 ![[video.mp4]]
       → 打开跟读工坊，即可解析视频和字幕

方式二：将 SRT 文件与视频文件放在仓库内
       → 在笔记中嵌入视频 ![[video.mp4]]
       → 插件会自动匹配同名 SRT 文件

七、常见问题

❓ 查词没有反应？

请检查以下几点：

1. 确保已正确配置词典（在线词典需要网络连接）

2. 如果使用 MDX 词典，请检查设置中是否正确填写了mdx、mdd、css文件路径

3. 确认当前语种设置正确

❓ 看不到刚刚添加的闪卡？

新添加的闪卡会出现在闪卡复习队列的最末位。

❓ B站视频只能下载到中文字幕？

请检查视频是否上传了除中文外的其他语种字幕。视频画面上的双语字幕是压制好的，不代表视频上传了所有的字幕文件。

❓ 跟读工坊打开 YouTube 视频显示要「登录」？

切换网络通常能解决这个问题。这种情况多与当前网络环境有关，尝试更换网络节点后重试即可。

❓ AI 解析报错？

请检查：

1. API 密钥是否正确配置

2. 网络连接是否正常

3. API 余额是否充足
